# 阶段15：采购经营约束

新策略检查自身毛利、固定成本覆盖、三轮固定开销现金缓冲，以及一次供应商报价上行和5%加工成本压力；当前与压力情景均须优于或等于各半采购。失败明确退回各半采购。只使用自身经营数据和公开报价规则。

预注册实验240场4800轮，0模型调用。72组全新参数/种子配对中56组福利改善、11组下降、5组持平；中位变化+0.7289%，最差-0.2541%，最差10%均值-0.1248375%，无额外退出。5456次有效决策释放1386次，约25.40%。工程回放、保存恢复、公开信息和共同冲击检查全部通过，所有预定实验门槛通过。

变化以福利差额除以 max(基线福利绝对值, 初始企业总现金) 归一化，不是投资收益率。旧失败组仅用于诊断。该结果适用于原成本系数模型，不能外推到新逐笔采购账模型或现实市场；下一阶段重新验证。
