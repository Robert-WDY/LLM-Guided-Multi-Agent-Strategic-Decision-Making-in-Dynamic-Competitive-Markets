# 续约否决研究线：结项说明（负结果 + 功效分析）

日期：2026-11-19。本文件结束 2026-11-18/19 的"店长 AI 建议器 hold / −4% / +4%"研究线，不再追加子研究。原始结果见 [final-report.md](final-report.md)、[renewal-risk.md](renewal-risk.md)，数据未改动。

## 结论

1. 续约风险规则在独立样本上提高了平均模拟利润（零售 360 市场 +10.26 [7.50, 13.26]），但**亏损率门槛（单侧 98.75% Clopper–Pearson 上界 ≤ 10%）一次也没有通过**。
2. 失败的主要原因是**样本量**，不是规则本身：在观察到的真实亏损率 ≈ 4.9% 下，门槛需要约 257 次实际改价才有 80% 概率通过（下表），而 360 市场只产生 81 次改价。
3. 同一开局的终局方差占比为零售 45.6%、生鲜 81.5%：单笔决策的终局标签以噪声为主。继续加子规则（前瞻否决层、晚期亏损否决、多续局/宽覆盖、重复首标签……）无法绕开这一点。
4. 生鲜 23/75 的亏损率（上界 44%）说明该市场下规则本身不合格，不是功效问题。
5. 结论主要由 SmolLM2 / Qwen2.5-0.5B 这类极小草稿模型驱动（换模型配对差 −17.12 [−33.55, −4.32]），不能推广为"LLM 策略决策"的结论。

## 功效分析

复算脚本见本文件末尾，结果与报告一致（4/81 → 上界 13.31%）。

| 真实亏损率 | 50% 通过所需改价次数 | 80% 通过所需改价次数 |
|---|---|---|
| 3.0% | 79 | 124 |
| 4.9%（观察值） | 152 | 257 |
| 6.0% | 257 | 453 |
| 7.0% | 465 | 845 |

按 81/360 ≈ 22.5% 的改价覆盖率，257 次改价约需 1,140 个独立市场。若未来重启这条线，应先按此表定样本量，再一次性运行，而不是分批追加。
