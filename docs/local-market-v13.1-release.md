## 发布验收发现并修复的问题

- API 的 60 轮创建枚举未跟随引擎更新，已补齐，旧配置继续执行自身合法轮数限制。
- `python -m` 服务与进程内协调器导入不同 API 模块，引发同一实验误判中断；入口统一到规范模块实例。
- 真人固定动作代理未传递采购数量、主备供应商与比例。修复后实际 HTTP 结算验证：1234 件，主供应商 resilient 占 60%，分配 740/494 件，付款 2,620,860 分，原料消耗 1234、报损 0；此前失败输出保留。
- 市场类型曾把消费偏好映射显示成高需求/断供/灾害，已按实际作用更名为质量/价格/服务偏好。
- PowerShell 5 与 7 的 JSON 日期和数组行为不同，进程归属校验统一为 UTC ticks 和展开后的列表。测试启动器捕获 PIPE 被后台子进程继承导致等待 EOF，验证脚本改用文件日志；原失败证据保留。

## 持久化与费用边界

每次 API 修改接受后持久化，运行中的标记也持久化；崩溃恢复保留已接受动作，缺失部分只用规则补齐。备份采用 SQLite backup API，恢复前校验数据库和存档 hash，保存旧数据副本。预算账独立，不随实验备份回滚。已用并发、失败/未知调用、输入过长、账本损坏/删除、报告超额等故障用例验证拒绝路径，原总预算维持 10 元，历史保留 7.008 元。

DeepSeek 高峰未缓存输入 3 元/百万 tokens、输出 9 元/百万 tokens，按不使用缓存及谷价优惠的上界估算；每调用 128000 输入/4000 输出上界预留 0.42 元。UTF8 输入包最多 124000 字节，剩余为消息封装预留。2026-09-07 重新核对[官方价格](https://api-docs.deepseek.com/zh-cn/quick_start/pricing/)，价格快照至 2026-09-08，过期禁止新付费请求。真实账单仍以供应商计费为准；本版验收没有通过真实网络验证新版本模型决策质量。
