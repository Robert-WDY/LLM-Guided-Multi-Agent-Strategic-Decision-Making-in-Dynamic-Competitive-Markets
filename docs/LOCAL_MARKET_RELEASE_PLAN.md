# 本机完整自主市场：实施与验收计划

用户确认（2026-09-07）：仅自己本机使用；企业、消费者、供应商、政府均自主决策。以本机可运行产品为交付终点，不部署公网、不以多租户为本阶段目标。真实模型仍受原10元累计预算约束，不因阶段推进自动增加额度。

“完整”指可运行且可核对的经济闭环、主体决策、用户操作和恢复能力；不表示穷尽经济机制，或承诺所有主体/策略总能获利。各主体先具备独立、可审计、可重复的规则决策；LLM与规则来源明确区分。

| 阶段 | 实现范围 | 验收后才进入下一阶段 |
|---|---|---|
| 15 采购经营约束 | 自身毛利、固定成本、现金缓冲、报价上行风险；失败则明确回退 | 工程回归、旧失败组诊断、全新种子/参数留出与退出/福利尾部检查 |
| 16 资金与物流闭环 | 明确上游销售和下游采购的金额/数量归属，处理未使用投入品，核对收付与福利，保留旧版本 | 逐笔收付、数量和现金不变量；压力/中断/完整回放实验 |
| 17 四类主体自主决策 | 企业经营及采购；消费者买/不买与商家选择；供应商报价/供给投资；政府预算内监管/支持 | 输入权限、目标与预算、动作时序、审计记录；逐机制与组合消融实验 |
| 18 本机完整界面 | 四类主体状态/决策、实验运行控制、结果与风险、配置/存档/导出、错误恢复 | 实际本机HTTP和用户操作路径验证、长局与中断恢复 |
| 19 本机发布 | 固定依赖与版本、一键启动/停止、端口与数据目录、离线规则运行、备份恢复和资源/费用限制 | 干净启动、进程重启、连续多局、备份恢复、最终全量测试与验收报告 |

当前本机发布版为v13.1，阶段15至19验收完成，最终418项后端/11项前端及启动/备份/费用/长局验证通过，冻结结果见 local-market-v13.1-release.md。阶段14的采购候选未推广，阶段17首版扩产的负结果保留并由回本约束修正。旧v10 beta1归档及历史实验不覆盖。每阶段单独保留注册、源码版本、实验输入/输出、负结果和结论，研究总记录同步本机镜像。

发现的新问题必须记录，并修复或明确限界后再通过对应阶段；不将“测试通过”替代用户流程/经济闭环验收，也不把阶段实验样本当成现实经济校准。
