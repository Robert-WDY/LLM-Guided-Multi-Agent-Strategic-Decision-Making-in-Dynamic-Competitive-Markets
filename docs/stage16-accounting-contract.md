# 阶段16：逐笔采购账契约

启用新协议 cash-material-v1.0.0，旧v11系数模型及哈希保持兼容。

1. 企业先扣除动作支出并预留固定开销，采购请求按剩余现金和所选供应商最高报价限制数量；实际付款按最终分配数量与当期报价逐笔结算。
2. 供应商收到对应货款，以交付数量计算生产成本，更新自身现金与利润。不凭未成交请求确认收入。生产采用订单预付模型，无贷款。
3. 企业加工单价仅包含原基础成本的非原料份额，采购发票全额进入本轮变动成本，不再用采购价系数再次扣原料成本。
4. 一件投入品支持一单内部履约，互助代工由实际加工者消耗原料；未消耗投入品本轮末作为易耗品报损，无跨轮库存和残值。此为明确的模型边界。
5. 当前收入可支付当期加工成本；负单位贡献订单受采购后剩余现金限制。互助只允许双方逐单贡献均非负，防止无资金担保的代工交易。
6. 供应商回款、生产成本及现金，企业采购付款，逐供应商分配/发票，消耗/报损均进入状态与存档；每轮检查对账。消费者收入来源、固定/加工成本收款方属于模型外部部门，不能宣称封闭货币系统。

阶段验收必须包括少现金、高成本、供给中断、低需求报损、互助、退出、长局、篡改拒绝与保存/回放一致性。新模型不以原系数模型福利提升作为门槛；门槛为账与物量闭合、非负现金和可复现。后续主体策略在此新模型另作组合实验。
