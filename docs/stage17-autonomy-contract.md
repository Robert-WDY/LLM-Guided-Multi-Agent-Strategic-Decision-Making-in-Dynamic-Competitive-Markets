# 阶段17：四类主体自主决策契约

本机版使用可审计的确定性规则主体；企业还可使用已有人工/模型决策入口。消费者是每轮进入市场的偏好与预算群体，不是具有跨轮工资、储蓄和信贷的家庭模型。逐单预算等于该群体当期支付意愿，明确记录买、不买、缺货及支出。

企业规则在自身现金/加工成本/上一轮需求和公开供给范围内选择采购数量与组合，数量受可支付现金硬约束；动作可由人工或模型覆盖，但结算不允许透支。

供应商同时根据自己的已结算销售、容量与现金独立决定下期报价和扩产；先报价再决定现金投资，投资当期扣款，下期可用，最后一轮不投资。不能读取另一供应商新动作或未来冲击。

政府使用自己的现金、上一轮公开缺货/集中度和活跃企业名单，安排预算内检查强度和普遍经营支持；不读取企业私有现金、未来行动或随机数。检查在当轮付费并影响协调案件识别概率，支持是政府与企业间转移，罚款反向转移；无借款与凭空预算。

政府初始资金及供应商初始资金是明确外生初始条件。监管/扩产/采购响应均有独立开关用于消融；消费者预算约束不可关闭。每种主体有版本、输入、动作、生效轮次和结算证据。福利是合成指标，政策选择不宣称最优。

验收：四方预算及输入权限、扩产时序、终局禁止投资、罚款/支持和成本对账；独立机制与组合消融、压力参数、多种子、自然退出、保存/恢复/回放；完整配置的公共建议器从合法公开输入重建合成账目并明示估计假设。
