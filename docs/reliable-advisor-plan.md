# Reliable Strategic Advisor：冻结市场后的研究计划

本轮采用用户粘贴文档的主线：冻结市场结算，以Agent原计划为主对照；条件响应、局部候选、多期限预测与弃权共同组成改进层。既有v17保留。不是新增市场、人格或一般均衡求解器。

## 阶段与验收

1. 冻结所有市场源文件、合法动作层、观察构造和现行配置的SHA256；新增机构账本位于市场外。费用保留原账，用户2026-09-08明确授权累计上限30元，失败/未知调用不退款。
2. 原计划按当前状态验证并保存实际执行动作；候选0必须逐字段保留合法原动作，只对单个维度局部扰动。研究模式H3并以H5再次验证，交互模式H1、不运行重诊断。训练/验证冲击分离；候选在发现集选择一次，再对该候选和原计划作配对下界和现金/退出检查。不通过即原动作。下界仅在声明的模拟分布内，不能保证真实收益。
3. 条件模型使用已结算公开价格变化、公开缺货率和自己已执行的服务投入。预测的是下一轮对手价格反应；本轮同时行动对手不获知候选。模型不读取对手人格、私有现金、成本或未来行动。冻结训练种子与模型参数，再在未见种子比较静态、一般倾向和条件响应；oracle仅评价器可用。
4. 四个实验：建议6市场×3人数×2目标×20新种子=720源状态；相同候选的搜索/一般倾向/条件响应消融及事后oracle；合作2门槛×3人数×3互惠×3背离×20种子=1080局；固定总市场与按人数扩展资源两套20种子对照。记录3/5轮目标差、利润、福利、最差种子、负收益率、弃权、预测校准、项目成功、信誉和未来接受。
5. API与原实验室集成原计划输入、模式选择、解释、保存恢复；独立重放、参数错误、隐私、时序、预算弃权及工程回归。现有Stackelberg真值作为条件反应小实验；只做少数参数数量级敏感性，不冒充现实拟合。
6. 真实模型：两模型×六新种子×alone/old/reliable=36核心决策单元，共用同源LLM草稿；分别记录建议质量、接受/拒绝选择及三轮结果。先完成四组零Token实验与工程检查；若可靠性前置门槛未通过，则明确阻止收费阶段，不以花钱补救失败。价格重新核对，原始响应与失败保存，禁止未知结果自动重试。

## 固定统计口径

主对照Agent Draft，规则仅辅助。每个源状态同时比较相同候选池；主样本每目标20独立种子，条件不是新增独立样本。95%配对bootstrap为探索性区间，未校正多重比较。按组收益通过：均值区间下限>0且实际下降率≤10%；高弃权率不能被记作有效性通过。工程通过、响应校准、收益通过、收费前置门槛分别记录。冻结后不得按留出收益调参；必要缺陷修补保留失败和前后hash。

现实数量级工作只选价格敏感度、经营利润率、服务效应、冲击频率、库存成本；没有匹配行业实测数据时，只报告敏感性与外部参照，不宣称校准通过。
