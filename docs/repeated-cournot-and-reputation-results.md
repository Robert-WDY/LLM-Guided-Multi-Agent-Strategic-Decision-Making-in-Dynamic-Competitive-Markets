# 重复 Cournot 与信誉响应真实模型实验

日期：2026-09-02
证据等级：小样本方向性真实模型证据，不是统计确认。

## 1. 重复 Cournot 闭环

### 设计

焦点 Agent 为豆包 Seed 2.0 Lite。固定 3 个协议 Seed、每个 10 轮，对比 `persona_only` 与 `exact_online_advisor`；对手为：

- `fixed_nash`：每轮固定产量 8；
- `adaptive_best_response`：根据焦点 Agent 上一轮产量计算精确最优反应；
- `deepseek_llm`：DeepSeek V4 Flash 根据双方公开历史做同时决策。

规则对手不消耗 Token。真实 LLM 对手和焦点 Agent 的提示都在任一方本轮行动生成前冻结，双方只能看到上一轮及更早历史。Advisor 使用公开历史形成对手产量分布，再穷举 0–30；不读取对手本轮动作。Provider 不支持可核验随机 Seed，因此三个 Seed 是市场协议与 Episode 标识，模型重复仍可能存在供应商侧非确定性。

### 结果

共完成 18 个 Episode、180 个结算回合。计划 240 次 Provider 请求；两次豆包输出为截断/多余 JSON，均在结算前被拒绝并原子保存。两次未完成 Episode 只重启自身，未重跑 7 个已完成 Episode，最终审计日志包含 248 次请求。18 条 Cournot Event Hash 链全部回放通过。

| 对手 | 配对 | 平均焦点利润增量 | 平均遗憾降低 | 利润正/平/负 | 平均价格变化 | 消费者剩余×2变化 | 总福利×2变化 |
|---|---:|---:|---:|---:|---:|---:|---:|
| 固定 Nash | 3 | +13.67 | +13.67 | 2/1/0 | +0.37 | -131.00 | -45.00 |
| 历史最优反应 | 3 | 0 | +5.67 | 0/3/0 | +0.07 | -28.00 | -4.00 |
| 真实 DeepSeek | 3 | +194.33 | +122.67 | 3/0/0 | +2.53 | -1023.33 | -192.67 |
| 总体 | 9 | +69.33 | +47.33 | 5/4/0 | — | — | — |

面对两个规则对手，Treatment 30/30 采纳建议。面对真实 DeepSeek，采纳率仅 33.33%，但三个 Episode 的焦点利润仍全部提高。无建议状态平均产量为 10.63、对手为 10.80、价格为 8.57；有建议状态分别为 9.13、9.77、11.10。Seed 910202 的无建议双方稳定在 `(12,12)`，价格等于边际成本 6，焦点十轮利润为 0；有建议轨迹避免了这一集体过量生产结果，焦点利润为 373。

这不是合谋证明。Treatment 相对 Baseline 更接近 Cournot-Nash，真实 DeepSeek 条件的平均 Nash 距离下降 2.33；但总产量下降仍抬高价格，企业利润改善同时降低消费者剩余和总福利。结论是精确私人利润建议能够缓解过量竞争，却可能产生企业目标与市场福利的冲突。后续研究必须并列报告二者，不能把“Agent 赢得更多”描述成“市场更好”。

配对在固定规则对手下具有清晰可比性；真实 LLM 对手会因焦点历史变化而产生不同闭环轨迹，因此它验证的是系统级 Treatment 效果，不是固定对手动作带上的逐轮因果效应。

## 2. 中性合作提示下的信誉响应

### 配置矛盾与修复

第一次 18 次原生 Agent 固定状态实验发现：市场 Observation 已启用 `shared_resilience_v1`，但历史稳定配置 `market_v4.yaml` 的 Persona Capability 仍为 `cooperation=false`。豆包据此明确输出“人格禁止合作”，DeepSeek却会越过该字段，造成信誉处理与能力冲突。该轮结果降级为缺陷诊断，不作为最终信誉结论。

曾尝试直接把 v4 Capability 改为 true，但全量回归立即在 Stage 6.9 历史 Advice Hash Replay 上失败。这说明不可变配置门禁有效：不能通过原地修改旧配置修复新功能。最终恢复 v4 原 Hash，新增实验级 `cooperation_capability_overlay`：只把 Capability 设为 true，所有合作效用权重仍为 0；Manifest 同时保存基础与有效 Config Hash。正式产品后续应发布 v5 配置，而不是改写 v4。

### 修正后设计

同一 Market State、同一私人 Proposal、同一 Balanced Persona、同一 `neutral_numeric_v1` 提示，只改变公司 A 的权威历史：

- `no_history`：可信度 50%，无已验证承诺；
- `recent_betrayal`：可信度 10%，一次承诺、一次背离；
- `repaired_after_betrayal`：可信度 70%，曾背离一次，之后有履约记录。

2 个模型 × 3 条件 × 3 次重复，共 18 次。三组真实 Market State Hash 完全相同，Observation Hash 因可见信誉历史不同而不同。

### 修正后结果

| 模型 | 无历史 | 近期背离 | 背离后修复 |
|---|---|---|---|
| 豆包 | 3 接受 | 3 接受 | 3 接受 |
| DeepSeek | 3 接受 | 3 拒绝 | 2 接受、1 忽略 |
| 合计 | 6/6 接受 | 3 接受、3 拒绝 | 5 接受、1 忽略 |

DeepSeek 形成清晰的信誉响应：近期背离使接受率从 100% 降到 0%，修复记录使其回升到 66.67%。豆包虽然收到同样的 10% 可信度和背离记录，并在文本中提到信誉，但行动仍 3/3 接受，说明对豆包而言 Credibility 主要进入解释，没有稳定进入接受决策。

伴随的本轮共享韧性贡献均值分别为：无历史 833,333 分、近期背离 500,000 分、信誉修复 916,667 分。但 Proposal 的目标是下一轮，当前贡献不是对该 Proposal 的履约，不能将此指标称为 Fulfillment；只能视为信誉语境下的同期合作倾向。
