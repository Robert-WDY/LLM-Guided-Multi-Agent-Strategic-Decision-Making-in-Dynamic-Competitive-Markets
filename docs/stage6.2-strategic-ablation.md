# Stage 6.2：战略模块下游消融

日期：2026-08-24。

## 1. 阶段目标

本阶段不增加市场动作，也不调用真实模型。目标是在完全相同的真实市场 Seed、人格和对手策略下，逐层比较：

1. `rule_baseline`：现有 Rule 运营策略；
2. `persona_planner`：公开市场长期 Rollout + Persona Utility，不使用 Belief 和 Opponent Model；
3. `belief`：在上一组之上加入公开动作信念；
4. `opponent_v1`：继续加入当前公开对手策略模型 v1；
5. `opponent_v2_candidate`：只在实验中替换为公开证据校准候选 v2。

实验要回答的不是“哪个解释更好听”，而是每一层信息是否改善真实 `MarketEnv` 中的企业价值、利润和精确一步反事实遗憾。任何未通过下游门禁的候选都不得自动进入在线默认配置。

## 2. 实验矩阵与因果边界

- 共同 Seeds：1、2、3；
- Persona：极端激进、短期逐利、风险防御；
- 对手池：Known、Mixed、Holdout；
- 条件：5 组；
- 每局：5 轮；
- 在线规划：2 轮视野 × 2 个情景；
- 总计：`3 × 3 × 3 × 5 = 135` 个确定性 Episode、675 个市场回合。

Known、Mixed 和 Holdout 对手都由固定潜在效用分布驱动，但会根据自己在各 treatment 中实际看到的状态响应。这表示对照固定的是“对手策略”，不是强行固定一条脱离状态的动作脚本。

每轮另用同一真实状态、同一组已生成对手动作，穷举焦点公司的全部公开候选并真实结算一步。由此得到的 `true_one_step_regret` 是精确事后一步遗憾，不使用 Advisor 自己的代理分数；但它仍不是多轮最优值、Nash 均衡或真实世界收益。

## 3. 共同随机数缺陷与修复

第一次完整诊断发现：真实市场虽然复用了共同 Seed，但公开 Advisor 的内部预测 Seed 来自完整决策输入哈希。加入 Belief、Opponent Model 或更换 Persona 会同时换掉模拟随机场景，导致“信息层效果”和“不同模拟抽样”混杂。

修复后分离两个哈希：

- `public_decision_input_hash` 继续绑定完整合法决策输入，用于 Advice 审计；
- `forecast_seed` 只绑定配置、公司、可见性、PublicState 和本公司 PrivateState。

因此同一合法观察下，Persona、Belief、Opponent v1/v2 共用同一组内部预测场景；这些 treatment 只改变效用或预测，不再顺带改变随机数。新增测试同时验证完整输入哈希不同、预测 Seed 相同、预测 MarketState Hash 相同。

| Persona Planner vs Rule | +4,333,212（+43,332.12 元） | +5,222,339 | +5,046,803 | +12,833 | 27 / 0 / 0 | +948,263 | 否 |

晋升门禁要求：平均企业价值不能下降、平均真实遗憾不能上升、最坏配对企业价值不能下降。四个处理都至少违反一项，所以没有新组件被自动晋升。

### 4.1 Persona Planner

人格规划在所有 27 个配对中都提高了五轮终局企业价值，且最差配对仍增加 948,263 分；短期逐利和风险防御的一步遗憾分别下降 453,647 和 101,870 分。唯一失败来源是极端激进人格的一步遗憾平均上升 594,017 分，使总体遗憾上升 12,833 分。

这说明长期 Rollout 的经营价值不是偶然平均值，但极端激进的数学效用权重仍和真实一步机会成本错配。当前 Planner 可以作为显式研究 treatment 保留，不能宣称已经对所有人格可靠。

另一个重要现象是 Planner 的平均企业价值和利润提高，但市场份额从 248,254 ppm 降到 228,057 ppm，第一名率从 55.56% 降到 14.81%，平均名次从 1.89 变为 2.26。135 次 Planner 决策中有 96 次提价；三种人格也都以提价为主。这表明当前目标更偏向绝对企业价值，而不是相对竞争排名，人格间的数学差异仍不够强。

### 4.2 Belief

Belief 将一步遗憾平均降低 102,010 分，而且三种人格、三类对手池的遗憾方向都改善；但五轮企业价值平均降低 257,155 分，11 个配对下降，最坏下降 2,891,198 分。

这暴露出两个可能原因：当前一步遗憾并不是五轮价值的充分代理；或者 Belief 虽改善下一步适应，却诱发后续价格路径恶化。下一阶段应同时保留“一步精确标签”和“多轮终局标签”，不能只优化其中一个。

### 4.3 Opponent v1

v1 相对 Belief 的平均企业价值提高 293,170 分，22/27 个配对非负；但中位数为 0，五个配对下降，最坏下降 441,406 分，并使一步遗憾增加 43,475 分。利润型人格是唯一同时满足企业价值不退步和遗憾下降的子组；激进与风险防御人格均出现遗憾上升。

因此 v1 有可利用信号，但当前 Planner 没有稳定地把信号转化为更好决策。v1 保持现有“可选研究输入”地位，不扩大默认使用范围。

### 4.4 Opponent v2 候选

v2 相对 v1 的 27 个配对中，24 个决策路径完全相同，3 个更差，没有一个更好。Known 池完全无变化；Mixed 和 Holdout 分别平均损失 119,552 和 86,728 分；风险防御人格完全无变化，激进和短期逐利分别出现一组和两组损失。

这给出了比上游 Brier/Cross Entropy 更强的否定证据：v2 的概率校准略好没有转化成下游收益，反而只制造尾部损失。候选 v2 明确不替换在线 v1；后续只有改变映射方法并重新通过 Holdout 下游门禁后才可再次申请晋升。
