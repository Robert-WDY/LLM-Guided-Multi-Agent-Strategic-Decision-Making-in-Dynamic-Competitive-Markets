# 项目意义说明书（对外一页纸）

> 用于回答两个问题：这个实验为了什么？怎么算赢？以及——我到底贡献了什么。

## 研究问题（一句话）

在动态竞争市场里，给一个决策者加上"博弈论式反事实建议"后，它的决策是否**可重复地、有统计证据地**优于它自己不做建议的基线？代价（尾部风险）是多少？

## 为什么值得做（意义）

现在到处都在宣称"LLM 能做定价、谈判、采购、博弈"，但几乎没有人**在预注册门槛下**回答"它真的比'不做'好吗"。这个项目的意义不是造一个赚钱的机器人，而是**用不能作弊的方法，测出战略推理的真实成色**——哪怕答案是"还不够好"。

## 我实际贡献了什么（技术难点，4 条）

1. **确定性可复现**：让"带随机性的多智能体市场"可以逐字节复现——固定 seed → 状态 hash → 回放校验，42.8 万次算术核验、550 项测试。任何结论都能被第三方重新算出来。
2. **信息隔离**：严格分离"智能体知道什么"和"评价者知道什么"，研究者的真实状态永不泄漏进建议器。否则建议器就是开卷作弊，谈不上博弈论。
3. **预注册 + 失败关闭**：实验前写死"怎么算赢"，过了就过、没过就说没过，不事后改门槛、不删负例。对抗"调参调到看起来成功"这个领域通病。
4. **反事实建议架构**：对手只对"已结算价格"做滞后反应、看不到你本轮未提交的动作；建议必须过"蒙特卡洛下界 + 现金约束"，否则弃权。这是反事实推理，不是事后诸葛亮。

## 预注册成功判据（怎么算赢）

| 指标 | 门槛 |
|---|---|
| 相对基线的均值增益，95% 区间下界 | > 0 |
| 干预负例率 | ≤ 10% |
| 覆盖率 | 利润 ≥10%、福利 ≥5% |
| 种子簇级"任一损失概率" 95% 上界 | ≤ 10% |

## 已得结果对照（v20.1，300 个新留出状态）

| 目标 | 均值增益 | 负例率 | 覆盖率 | 尾部风险上界 | 结论 |
|---|---:|---:|---:|---:|---|
| 利润 | +9,399 合成元 [7,474, 11,309] | 1.20% | 55.33% | **10.56%** | 差 0.56pp 未过 |
| 福利 | +1,318 [−301, 3,387] | 20% | 3.33% | **65.74%** | 远未过 |

误差归因（49 例 A/B/C/D 分解）：**主要误差来自"公开信息下无法识别对手的隐藏状态"**，不是策略模型本身。

## 诚实的边界（没做到什么）

- 所有数字是**合成元**，不是现实市场校准；绝对数值无现实含义，只有"建议 vs 基线"的相对差有含义。
- 最近 v19→v20.1 是 **0 token** 实验：Agent 原计划来自规则策略（TFT/Grim/WSLS）、对手响应是拟合模型，**没有调用真 LLM**。结论是"这套方法能测出什么"，不是"LLM 推理已被证明有效或无效"。
- 真实 LLM 采纳验证是门禁之后的下一步（30 元累计预算、价格核验未过，暂不启动）。

## 一句话对外话术

"我在做一件大多数 LLM-agent 论文跳过的事：用**可复现、信息不泄漏、预注册**的方法，去测'给决策者加博弈论建议到底有没有用'。我的主要结论是一个能站得住的负结果——误差主要来自隐藏状态、福利建议在公开信息下基本不可解——这告诉领域真正的问题在哪，而不是假装一个玩具赢了。"
