# 中期第一批与第二批实验结果

日期：2026-09-03。

## 1. 本轮执行原则

本轮不是继续堆叠功能，而是对当前市场、合作、人格、信念、对手模型和战略建议器做分层验证。先运行可精确重放的零 Token 实验；只有当经济方向和安全门禁成立时，才允许新增真实 LLM 调用。

结果是：本轮没有新增真实模型调用，新增 Token 与费用均为 0。原因不是实验未执行，而是原生合作激励和复杂市场 Advisor 均未通过付费门禁；继续调用模型只会把市场或 Planner 缺陷误归因为 LLM 行为。已有真实模型结果被纳入证据审计，但没有重复付费。

## 2. 第一批：市场、合作与 Advisor

### 2.1 市场和消费者模型

`runs/midterm-market-validation-v1/summary.json` 使用 20 个 Seed、4 个市场模型，共 80 个配对单元；另运行 200 个动态市场回合。

全部 80/80 单元满足：

- 焦点公司降价提高潜在需求，提价降低潜在需求；
- 广告提高认知，服务提高质量；
- 100 万分产能投资按配置精确形成下一轮 100 单产能资产；
- 私人韧性投入提高私人韧性存量；
- 需求闭合、份额和为 100 万 PPM、利润和现金账目均精确一致；
- 200 个动态回合没有出现四家公司份额同时严格上升或同时严格下降这一不可能现象。

这证明市场的基本会计恒等式、消费者响应方向和份额闭合正确。它不证明参数已经现实校准。

### 2.2 公共韧性、搭便车和私人合作激励

`runs/midterm-first-batch-free-rider-matrix/summary.json` 使用 20 个新 Seed、10 轮持续高供应冲击，比较全员贡献、1 个搭便车者和全员不贡献：

- 搭便车者每轮不支付贡献成本，但仍获得平均 30,089,398 分公共保护收益；
- 搭便车者相对三名贡献者的累计利润平均高 5,664,309 分；
- 少一名贡献者使最终行业韧性降低 131,941 PPM；
- 全员不贡献使最终行业韧性降低 725,693 PPM，缺货订单平均增加 10,672.05 单，市场累计利润平均减少 124,008,204 分；
- 搭便车者相对“自己也贡献”的累计利润平均低 764,478 分，说明它有相对竞争优势，但在高风险长期环境中未必提高自身绝对收益。

因此当前市场确实形成公共品、搭便车和集体行动失败。与此同时，`runs/midterm-market-validation-v1/summary.json` 对 100 万分单次贡献做 20 Seed、未来 3 轮私人价值反事实：正常和强制灾害的四个条件全部为 20/20 负值，最接近正值的强灾害条件均值仍为 -379,679 分。当前机制没有构造出“一个私人最优合作、一个私人最优背离”的可识别处理，所以原生市场付费合作诱因实验门禁关闭。

这两个结论并不矛盾：合作可提高全市场长期福利，同时单个公司的边际贡献仍可能被搭便车严格支配。这正是公共品困境，但也意味着不能用当前参数测试 LLM 是否会在正私人回报下合作。

### 2.3 信誉、报复和宽恕

本轮复核已有、未被配置缺陷污染的真实模型证据：

- `runs/cooperation-reputation-neutral-real-v2/summary.json`：DeepSeek 的接受率为 `100% → 0% → 66.67%`（无历史、近期背叛、背叛后修复），显示报复和部分宽恕；豆包三组均为 100%，只在理由中引用信誉，动作不响应；
- `runs/cooperation-full-chain-real-v2/summary.json`：两个模型各 3 个 Seed，6/6 接受、6/6 全额履约，Proposal、Commitment、Actual Contribution、Verification 和四层 Replay 均通过。

这些结果证明信誉信息能影响部分模型，也证明生产闭环能正确识别履约。它们仍不是自然发生背叛后的长期重复博弈轨迹。由于当前私人合作诱因门禁失败，本轮没有再运行付费重复轨迹，避免把提示、模型偏好和错误经济激励混在一起。

### 2.4 Advisor v8 开发与未见 Seed

`runs/stage8-advisor-v8-zero-token/development/summary.json` 在 300 个开发窗口中冻结一条公开信息执行门禁，放行 37 次，37 正、0 负，覆盖率 12.33%。随后不再调参，直接在 10 个完全未见 Seed、600 个窗口上验证：

- 放行 77 次，覆盖率 12.83%；
- 67 正、10 负；
- 放行样本平均企业价值增量 +694,550 分；
- 最坏放行样本 -327,970 分；
- 最坏 Seed×Persona 组均值 -16,280 分；
- 隐藏状态泄露为 0。

覆盖率和总体均值通过，但“无负放行、最坏样本非负、最坏分组非负”失败，因此 v8 未晋级，真实 LLM Advisor 实验门禁关闭。失败说明问题不只是阈值，公开预测状态和候选排序仍存在系统误差。

## 3. 第二批：人格、Belief、Opponent Model 与信息价值

### 3.1 10 Seed 战略消融

`runs/midterm-second-batch-stage62/summary.json` 使用 10 个新 Seed、3 种人格、已知/混合/未见三类对手池、5 轮，共 90 个匹配单元。每个单元依次比较规则基线、人格规划、Belief、Opponent v1 和 Opponent v2；不调用 LLM。

| 增量模块 | 平均企业价值变化 | 正/零/负配对 | 最坏配对 | 单步真实遗憾变化 | 晋级 |
|---|---:|---:|---:|---:|---|
| Persona Planner vs Rule | +3,049,027 | 85 / 0 / 5 | -2,241,687 | +266,484 | 否 |
| Belief vs Persona | -481,859 | 25 / 25 / 40 | -5,131,486 | -127,118 | 否 |
| Opponent v1 vs Belief | +330,886 | 40 / 32 / 18 | -3,802,072 | +109,934 | 否 |
| Opponent v2 vs v1 | -116,387 | 0 / 76 / 14 | -1,758,016 | -24,205 | 否 |

Persona Planner 在未见对手池为 30/30 正，说明数学人格层有很强的平均价值；但在已知/混合池仍有负样本，而且平均单步遗憾上升，因此不能称为稳定最优。Belief 虽降低单步遗憾，却降低长期企业价值，说明单步代理目标和长期经营目标没有对齐。Opponent v1 在已知对手上最好（平均 +688,920），到混合对手几乎归零（+25,496），未见对手仍有 -3,802,072 的尾部损失，存在明显泛化问题。Opponent v2 没有任何正样本，不能晋级。

长轮次预跑还发现一个实验实现缺陷：公开预测状态中的候选标签可能在真实状态候选集中因边界去重而消失，旧遗憾计算会异常退出。现已改为直接结算 Agent 实际选择的动作，而不是在另一候选集中按标签查找；相应测试和本轮完整矩阵通过。

### 3.2 Belief 的真实 LLM 证据

复核 `runs/belief-real-paired-20260821/summary.json`：36 次真实豆包调用、403,439 Token。固定状态中 Belief OFF 明确引用率 0/3、ON 为 3/3，3/3 动作改变，价格平均下降 66.67 分；多轮 3 Seed 中自身利润为 2 正 1 负，均值 +850,777 分。预测准确率仅 44.44%，Brier 0.6631，Log Loss 1.0694，只略好于三分类均匀基线。

合法结论是“LLM 会读取 Belief 并改变动作”，不是“Belief 已提高长期收益”。结合本轮 90 配对消融中 Belief 平均降低企业价值，当前应先升级预测器和长期目标对齐，不追加真实模型样本。

### 3.3 人格数学层和真实行为

已有 P1 真实消融共 22 次成功决策：在财务压力状态中，激进人格的完整配置和仅保留权重条件都产生显著广告投入，而仅标签、仅目标和仅 traits 大多退化为零投入，说明结构化效用权重比人格名称更能稳定驱动动作。P2 的 4 个真实 Episode、20 次决策显示不同人格形成不同投入和价格路径；极端激进人格累计利润为 -12,041,283 分、企业价值 28,575,566 分，暴露“符合激进方向”不等于“在激进目标下做得好”。

本轮 90 配对进一步证明 Persona Planner 不是纯解释层：它显著改变建议，并有较强平均收益；但仍有尾部损失和遗憾错位，暂不进行跨模型付费复制。

### 3.4 单一 Agent 完全信息

`runs/midterm-second-batch-privileged-mock/summary.json` 使用 10 个新 Seed、5 种人格、公开/特权两条件，共 100 个 Episode、1,000 次 Mock 决策：观察隔离、公司级完全信息、Replay 和配对随机性全部通过；但 Mock 策略不读取新增私有字段，两条件的企业价值、利润、份额和名次变化全部为 0，第一名率同为 6%。

已有豆包先导中，3 种已完整运行人格在完全信息下企业价值变化分别为 +8,773,398、-2,836,100、+773,150 分，3/3 仍为第 4 名。它已经否定“只要给完全信息，不管人格都能第一”的强命题。下一处理应是“完全信息 + 状态比较摘要”，再之后才是“完全信息 + 反事实决策器”，不能把后两者效果归因给原始信息本身。

## 4. 本轮最终门禁

| 项目 | 是否允许新增真实 LLM 扩样 | 原因 |
|---|---|---|
| 原生合作诱因 | 否 | 4 个私人边际回报条件全部为负，缺少正/负处理分离 |
| 复杂市场 Advisor v8 | 否 | 未见 Seed 出现 10 个负放行和负的最坏分组 |
| Belief 扩样 | 否 | 预测接近随机，零 Token 长期价值为负 |
| Opponent v1/v2 扩样 | 否 | v1 尾部损失大，v2 无正样本 |
| Persona 跨模型复制 | 暂缓 | 平均收益强但尾部与遗憾未对齐 |
| 完全信息扩样 | 否 | “信息即优势”已被否定，应先实现信息利用处理 |

本轮新增真实 LLM 调用为 0，新增 Token 为 0，新增费用为 0。历史真实证据的 Token 继续按原实验文档记账，不重复计入本轮。

## 5. 下一步（不是本轮自动执行）

优先修复三件事：

1. 为公共韧性加入可审计的公司级边际收益归因，构造至少一个私人合作回报为正、一个为负的处理；
2. 让 Advisor 用真实动作级反事实误差训练/校准公开预测，而不是继续调放行阈值；
3. 将 Belief 的动作分类升级为经过校准的策略分布，并以长期企业价值而非单步遗憾作为晋级主指标。

完成零 Token 未见 Seed 门禁后，再各做最小 2 模型 × 3 Seed 真实验证。
