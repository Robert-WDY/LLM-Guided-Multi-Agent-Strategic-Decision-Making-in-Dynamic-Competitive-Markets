# 1/2/4 LLM 四主体市场多 Seed 对照结果

## 实验设计

- 市场构成：`1 LLM + 3 Rule`、`2 LLM + 2 Rule`、`4 LLM`
- Seed：101、102、103，三种构成使用完全相同的 Seed
- 每个 episode：4 个主体、20 轮
- LLM：Doubao 默认模型，`balanced` 人格
- 采样：temperature=0、top_p=1
- 总规模：9 个 episode、180 个市场轮次、720 条主体轨迹、420 次真实 LLM 决策
- 有效性：420/420 次 LLM 决策成功，0 次 LLM 回退；9/9 episode 通过状态版本、原子结算、事件完整性和重放检查

Seed 101 使用已有基线结果，Seed 102、103 为本轮新增结果。

## 配对差异

以相同 Seed 下的 `1 LLM + 3 Rule` 为基准：

| 对照 | Seed 101 总利润差 | Seed 102 总利润差 | Seed 103 总利润差 | 三 Seed 平均差 |
|---|---:|---:|---:|---:|
| 2 LLM + 2 Rule | -14,311,161 | -20,950,616 | +6,237,728 | -9,674,683 |
| 4 LLM | -22,340,563 | +57,159,735 | +31,418,239 | +22,079,137 |

因此，当前结果不支持“LLM 越多，市场一定越差”或“一定越好”。4 LLM 在两个 Seed 中明显提高市场利润，在一个 Seed 中明显降低利润，效果受到市场冲击和供需路径强烈调节。

## 主体自身收益

- 1 LLM 市场中，LLM 相对规则主体的单体利润优势分别为 104,232、2,731,405、2,472,455，三个 Seed 均为正，平均优势 1,769,364。
- 2 LLM 市场中，LLM 相对规则主体的单体利润优势分别为 2,056,605、4,250,241、615,938，三个 Seed 也均为正，平均优势 2,307,595。
- 固定比较始终由 LLM 控制的 company_A，其三 Seed 平均利润从 1 LLM 市场的 25,823,834，变为 2 LLM 市场的 22,837,909、4 LLM 市场的 30,527,285。

这说明 LLM 在混合市场中表现出小而一致的个体收益优势，但增加其他 LLM 会改变竞争环境，company_A 的收益并不单调变化。

## 策略趋同

LLM 同轮价格的平均离散程度：

| 市场构成 | Seed 101 | Seed 102 | Seed 103 | 三 Seed 均值 |
|---|---:|---:|---:|---:|
| 2 LLM + 2 Rule | 71.25 | 40.00 | 110.00 | 73.75 |
| 4 LLM | 4.33 | 0.00 | 0.00 | 1.44 |

4 LLM 在 Seed 102 和 103 的每一轮都选择完全相同的价格；Seed 101 的价格差异也极小。完整动作向量仍有差异，4 LLM 的同轮完整动作完全相同比例为 16.4%，高于 2 LLM 的 6.7%。

这是目前最稳定的发现：在没有通信的情况下，相同人格、相同模型和相似状态使多个 LLM 产生高度同质化定价。它不等价于主动合谋，但会降低策略多样性，并可能形成类似默契定价的市场结果。

## 综合解释

1. **个体层面**：在两种混合市场里，LLM 的平均利润均高于规则主体，而且三个 Seed 的方向一致。
2. **市场层面**：LLM 数量对总利润没有单调效应；4 LLM 对不同市场路径表现为“高收益但高敏感”。
3. **行为层面**：LLM 越多，平均产能和韧性投入越低。4 LLM 的平均产能投入比 1 LLM 低约 61.6%，平均韧性投入低约 52.9%。
4. **供给风险**：4 LLM 的平均缺货损失最高，但主要由 Seed 101 的 2,912 单驱动；Seed 102、103 均为 0，说明这是条件性风险而非必然结果。
5. **同质化风险**：4 LLM 定价高度趋同，比利润均值更跨 Seed 稳定，是下一阶段应优先验证的研究问题。

## 当前结论边界与下一步

当前 n=3，只适合报告方向、效应量和机制线索，不适合宣称统计显著。建议下一步：

1. 扩大到至少 10 个共同 Seed，并报告配对差值的置信区间。
2. 做人格异质性对照：4 个 balanced 对比 balanced/aggressive/conservative/selfish_long_term 混合市场。
3. 做模型异质性对照，区分“相同人格”与“相同基础模型”各自造成的定价趋同。
4. 增加定价趋同指标、动作熵和产能不足预警，作为四主体实验的标准输出。
5. 在实验解释中将“无通信下的同质化”与“有意合作或合谋”严格区分。
