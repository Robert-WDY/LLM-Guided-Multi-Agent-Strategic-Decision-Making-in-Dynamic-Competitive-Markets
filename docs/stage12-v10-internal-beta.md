# v10 内测交付与实验边界

本阶段按“界面与恢复 → 参数/组合实验 → 内测冻结 → 10 元内真实模型实验 → 决定扩展”的顺序执行。工作目录为本机仓库，原 F 盘数据与既有实验不改写。

## 已完成的工程部分

- 前端提供 v10 三类多目标人格、主/备供应商与采购比例；显示实际采购、消费者剩余、上下游利润、政府预算、外部性和总经济福利。主备按比例同时下单，并非缺货后自动补单。
- “我的实验”支持保存、读取存档、恢复和 JSON 导出；后端操作自动写入 SQLite。恢复保留市场、结算历史、待接受动作、通信/合作/信念/对手账本、记忆、效用累计器和重复请求缓存。Provider 客户端与 API Key 不序列化。
- 中断协调器调用不会自动重试；显式恢复保留已接受动作，以规则补齐缺失动作，结算中断轮。未提交的界面滑块不属于已接受动作，恢复后应重新确认。
- 修复人工采购字段在协调器中丢失、新人格回退旧注册表、客户端重建时效用累计器丢失，以及公开建议器未恢复 v8/v9 供应链和福利字段的问题；公开候选保留采购策略。
- 真实模式的通信/信念/回合页改为读取已记录证据。高级交互仍是研究型记录界面，尚非面向普通用户的完整分析产品。

## 验证

后端全套 348 项测试通过；前端类型检查、Lint、生产构建与 8 项测试通过。独立 HTTP 进程实际退出后重新启动，保存状态 Hash 相同；重复 HTTP 结算不会重复记账，采购分配保留。相关机器可读证据随冻结版本保存。

`v10_beta_validation`：12 个新种子，前 6 个开发、后 6 个留出；4 个组合策略各运行 20 回合，9 个参数变体 × 3 个采购策略各运行 8 回合，共 372 场、3,552 次结算，逐场完整回放。需求守恒、现金非负、福利恒等式、上游利润记账、公开信息隔离和回放门禁均通过。

参数实验在 6 个留出种子上，基准分散采购相对集中低价采购的累计福利均为正；集中高可靠供应商有正有负，最差结果明显变差。三类社会目标在基准条件下均选择分散采购，提高可靠供应商价格后部分人格回到低价采购。结果来自合成市场和预设政策的权威模拟比较；它们不能证明真实企业会采取相同策略，也不能当作 LLM/建议器效果。

## 真实模型方案

官方价格于 2026-09-07 核验：[DeepSeek 模型与价格](https://api-docs.deepseek.com/zh-cn/quick_start/pricing/)。采用 `deepseek-v4-flash` 高峰缓存未命中输入 3 元/百万 Token、输出 9 元/百万 Token 保守记账，不减去缓存或空闲优惠。每次请求先持久化预留：输入上界 64,000 Token、输出强制上限 4,000 Token，单次 0.228 元；最多 32 次，预留最多 7.296 元，硬上限 10 元。发送前校验 UTF-8 字节上界；所有失败/中断保留预留，不自动重试。

预注册 v1 使用 2 轮公开历史，16 个预检场景全部因门禁弃权，因此未执行。旧 v6 成熟短缺场景在 v10 预检的前 10 个种子中焦点企业均已退出，不作为可决策样本。v2 保留正常供给/经济供应商中断两个 v10 场景，使用 4 轮真实模拟历史，门槛不变。相同状态、模型、人格分别执行基线与实际发布建议条件；无建议时只执行基线，避免为相同输入重复付费。无完整且实际暴露建议的配对，不作建议效果结论。

实际结果在冻结后另存，不能在本文件提前声称成功。此样本仅为单供应商、工程化固定状态下的方向性证据，不代表自然多轮因果效果。

## 内测范围

冻结包包含源文件 SHA-256 清单、源码 ZIP、依赖版本和验证证据。配置 Hash 不匹配的存档拒绝恢复。单机、单进程、本地可信研究控制台是当前支持范围；多进程共享状态、用户/租户隔离、容量压测、完整可视化回放与真实经济标定尚未验收。JSON 导出用于分析；继续实验使用本地数据库存档。SQLite 数据库备份应在停止后端后复制整个 `.local-state` 目录。

扩展供应商还是政府，应在本轮真实模型结果后决定。下一项机制扩展需给出独立研究假设、控制变量和成本/风险指标，不能仅因现有工程门禁通过而同时扩展两端。
