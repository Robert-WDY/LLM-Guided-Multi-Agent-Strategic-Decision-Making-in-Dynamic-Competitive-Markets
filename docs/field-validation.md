# 企业自由采纳定价建议能赚多少钱？现场验证方案

**截至 2026-11-18，本系统的真实企业利润效应仍未测量。** 本次完成了一个外部现场实证量的原文复核，以及可运行的市场分配、净利润分析和模拟验收。现场主问题是：向一个市场内所有已登记经营单位开放本系统、保留经营者最终报价权，在完整经营窗口内，平均每个登记单位能增加多少扣完成本的利润？拒绝建议、建议器弃权、没人点开和客户没有下单，都属于这个问题的答案。

**实际复核。** 下载并校验了哥伦比亚大学公开作者稿，从 PDF 的上述三页提取报告值。平均每条报价明细毛利分别为 94.16 与 105.11 美元，重算差值 10.95 美元，相对差 11.63%。由作者给出的报价内聚类秩和检验 Z＝−2.132 重算双侧 p＝0.03301，与报告的 0.033 一致。该检验针对分布，不能把 Z 当作均值差的标准误来编造 10.95 美元的置信区间。另据表 3，客户接受报价的 probit 系数为 0.154，标准误 0.076，由舍入数重算近似 95% 区间 [0.005，0.303]，单位是潜在指数。此处复算的是已发表实验的汇总数据，未获逐笔交易，也没有以原始数据重拟合模型。[复核输出与原稿哈希](../experiment-results/field-validation-v1/external-b2b.json) · [提取与重算代码](../scripts/field_validation/check_published.py)

## 分配、干扰与经营者自主权

1. **事前锁定人群及窗口。** 与参加方约定商品品类、市场区域、报价合法范围、处理起止日期、退货及账期成熟日。按试验前客户重叠、商品替代关系和同一人跨店操作连接经营单位，把强连接放入同一市场；保留跨市场边的数量和历史销售权重。以历史全品类净利、规模和季节性等匹配出每组三个独立市场，固定经营单位名册、版本、统计口径和随机种子。营业窗口全程保留分配，避免上周建议在下周对照中继续生效。
2. **先分配市场，再分配经营单位。** 每个匹配组三个市场随机取得 0%、50%、100% 的开放比例。50% 市场在事前名册中抽取恰好半数单位开放，故工具要求市场事前能分成偶数个单位。名单不符合条件时应在随机前重定单元或重新设计饱和度。0% 与 100% 市场比较测得包含市场内竞争、替代及相互学习的部署 ITT。50% 市场中未开放单位与 0% 市场的差衡量同市场部分开放的溢出。50% 内开放与未开放单位的差衡量在该固定饱和度分配下的暴露对比，精确半数分配会使两者面对的已开放同伴数相差一；该对比依赖此设计。
3. **记录草稿，再决定是否展示。** 两组在同一报价流程锁定可执行草稿和时间。开放单位在风险规则放行时才看到建议，可保持、部分采用、完全采用、修改为别价或退出；最终提交由经营者决定。弃权、技术故障、意外向对照展示均留在原分配。影子建议仅向评估者可见，展示前固定模型版本、规则及证据时间戳。实际发出建议产生的成本归入相应单位。为研究额外运行的对照影子推理单列研究成本，避免用它抵消真实部署费用。
4. **解释跨市场干扰。** 主比较要求各匹配组在事先声明的边界外干扰可忽略。试验前保存客流重叠图与主要跨市场竞争者，运行中记录跨组曝光、跨店人员及可独立取得的历史竞争报价。分别报告边界单位和内圈的事前分组敏感性。在跨区流动广泛、参与份额很低或市场边界失效时，100% 指登记单位全开放，其估计量仍受其他企业既有定价制度约束；市场均衡和平台全面部署效应保留为未识别。[Airbnb 市场实验](https://doi.org/10.1287/mnsc.2020.01157)

## 最小数据合同

| 粒度 | 必存字段 |

| 报价机会 | 唯一机会 ID、经营单位、时间、当时可见历史的版本、预先定义的合资格标记、原草稿与合法区间、建议与放行/弃权、实际展示、负责人自主选择、改后申请价及执行价、是否成交、关联订单和退货。区分明确接受、部分跟随、原价偶合和系统自动动作。采纳比例只在相应可见分母中描述，同时报告每个分母的数量。 |
| 经营账 | 所有登记单位在同一固定窗口内的**全部相关品类**销售、退款、已核销货物成本、履约补贴及费用、手续费、退损报废、审核工时折算、推理费用、其他增量运营或摊销成本；各项金额与财务账勾稽。原销售额按扣交易折扣、退货前且不含代收税口径计，退款单列；成本扣除退回可再销售货物的成本冲销，避免退货和报废双扣。单独列实施固定成本的摊销范围及期限。 |
| 经营状态 | 停业/退出和生效时间、原因、未完订单及最终清算、跨市场转单、数据是否齐账。真零成交、停业清算毕和账目缺失有不同标记。无交易仍可能发生人工、推理或退款成本。 |

主结果为固定窗口**未折现、已扣增量成本的贡献利润**，以每个预登记单位为分母。展示、采纳和成交都是处理后的结果，不用它们筛减 ITT 样本。每个市场先求单位均值，每个匹配组计算 100% 减 0%，最终各组等权。两侧 95% 配对 t 区间以独立匹配组为单位；在样本很少或单个大市场主导时，正态近似的解释力有限。两项溢出/暴露比较属次要分析。该口径估计典型登记市场内每单位的收益；若大市场应获得更高业务权重，须事前另订并实现相应估计量。自主采纳者和拒绝者的事后利润差混合了选择，销售负责人接受建议与客户接受报价也必须分开。

## 功效、退出与决策

- 先做历史 A/A 或盲态基线，按拟用市场、完整窗口与匹配方式算出市场内每单位净利，再估计匹配市场差的标准差。用**部署净 ITT**指定最小重要效应，包含风险规则的覆盖率、预计自主采纳和运行成本。在仅作规划且只对被采纳报价生效的简化情形中，覆盖率乘采纳率再乘每次增益才是稀释后的机会级毛增益；展示审核和固定费用仍需扣除。正式 ITT 直接使用账目，无需这个假设。
- 示例假定净 ITT 为 10 货币单位、匹配市场差标准差 25，双侧 5%、功效 80%，非中心 t 计算需要 **52 个完整匹配组，即 156 个市场**。预留 10% 整组不可用风险时规划 58 组（174 市场）。两项输入均为示例。增加一个市场内的订单数不能替代独立市场。实际商户数、方差或有效独立簇不足时，报告可检测的效应和区间，只做可行性评价。[功效与模拟输出](../experiment-results/field-validation-v1/synthetic-qa.json)
- 商户可随时停止看到建议。已随机单位保留原组，按协议完成已获授权的财务结算；永久停业只在所有未完订单清算后计实际损益。撤回数据授权、缺账等情况标为缺失，报告每组比例及原因。工具会停止主结果计算。若事前给定可信的净利上下限，可另做最坏/最好界限敏感性，不得把未取得的财务结果填为零。功效预留不构成事后删除退出组的理由。
- 在开启试验前由经营方确定依法可执行的价格范围、毛利或客户损害停止标准、责任人，以及是否采用具备相应推断方法的序贯设计。本方案默认固定终点；运行中可因越权定价、对账失效或预定业务安全条件关闭展示，并记录何时停止和既有分配。提前停止时单列结果及原因。商业判断看 100% 对 0% 的净 ITT 区间是否超过事前经营门槛，并一起核对退货、投诉、断货及竞争外溢。当前尚缺企业授权、真实名册、基线方差、经营阈值及财务对账。

## 离线运行与验收结果

分配 CSV 字段为 `block_id,market_id,unit_id`。结算 CSV 每个登记单位恰好一行，字段为 `unit_id,reconciled,eligible,shown,adopt_exact,adopt_partial,gross_sales_cents,refunds_cents,cogs_cents,fulfillment_cents,fees_cents,shrink_cents,review_cents,inference_cents,other_cost_cents`。金额使用同一币种最小单位的非负整数，负净利由收入减成本自然产生。本实现按 100 个最小单位折算一单位币值，适用于人民币或美元。数据准备阶段先将可能为负的成本冲销净额按统一收入/抵扣口径核对，如字段仍有负数须扩展会计映射，不可取绝对值。会计已核对设置 `reconciled=1`。运行环境需要 Python、SciPy，模拟验收另需 NumPy。真实采用的输入可保存在企业本地。

```powershell
python scripts/field_validation/trial.py assign roster.csv allocation.csv --seed 817 | Set-Content -Encoding utf8 locked-assignment.json
# 在出结果前将 locked-assignment.json 连同版本号和试验时间戳封存；分析时读取封存副本。
$assignmentHash = (Get-Content -Raw locked-assignment.json | ConvertFrom-Json).allocation_sha256
python scripts/field_validation/trial.py analyze allocation.csv ledger.csv --seed 817 --allocation-sha256 $assignmentHash --output field-itt.json
python scripts/field_validation/trial.py power --net-itt 10 --paired-sd 25 --reserve 0.10
python scripts/field_validation/check_design.py
```

A/A 使用 36 个匹配组、432 个**模拟单位**，三个经营收益对比均精确为 0。注入覆盖率、部分采纳、溢出与费用后，全面开放净 ITT 为 14.50、半开放市场未开放单位溢出为 2.00、半开放市场内开放与未开放差为 10.50，均与设定真值一致。另在 10,000 组高斯配对差模拟中，零效应误报率为 5.08%，注入示例效应后的检出率为 80.65%。已查验名册次序不影响分组、改动分配会被拒绝、缺账及重复账目会停止计算；误向对照展示保留在 ITT。以上数据来自人工设定过程，只验证分配和分析器。外部实证复核可运行 `python scripts/field_validation/check_published.py`（需 requests、pypdf 与网络），或提供已归档的作者 PDF 用 `--pdf` 离线重算。[分配和估计代码](../scripts/field_validation/trial.py) · [模拟验收](../experiment-results/field-validation-v1/synthetic-qa.json) · [外部已发表实证复核](../experiment-results/field-validation-v1/external-b2b.json)
