# 本机四方市场 v14.0.0：实现、验收与结论

适用范围：用户自己在本机使用的合成市场研究软件。默认启动配置为 configs/market_v14_local.yaml，入口为外层 START_MARKET.cmd，地址 http://localhost:3210/。真实模型指实际供应商 API 调用；模拟市场金额不是现实交易金额。

## 实验结论

- 合作：在当前参数下，搭便车可以比持续贡献获得更高利润，部分群体的福利也更高。公共投入不能被预设为必然有益。
- 供应商：普通资本下平衡与禁新借款相同；低资本激进备库存出现破产。可靠性策略在该组平均福利略高，不能推广为普遍最优。
- 政府：消费者返还及已投入韧性的报销是转移，不凭空提高总福利。无价格协调的情境中，执法只增加成本；政策学习没有证明优于保留预算。
- 共同学习：第一组留出实验中冻结人口略好、在线探索较差；下一组新种子中冻结人口也低于基线。结果对情境敏感。
- 神经模型：训练损失下降，但新种子平均福利低于规则基线，因此作为研究选项保留，不把训练成功等同经营效果提升。
- 真实长局：两家模型、两个共同种子，每局连续10轮；四个角色代表每轮独立调用，其他企业及另一供应商继续自主规则决策。160次有效选项全部实际执行并重放。规则平均福利574959348分，豆包568308263.5分，DeepSeek578981574.5分（分别约-1.16%、+0.70%）。只有两个种子，不能据此断言普遍优劣。
- 长期目标诊断：对每次选择进行了三轮折扣反事实比较，企业、供应商、消费者仍有偏离条件最优的选择。选项执行率100%不等于建议有效率100%，也不证明长期最优。

## 失败、费用与恢复

最终验收：后端444项全部通过；前端生产构建、11项测试、类型检查及lint通过，Python依赖检查无冲突。浏览器实际完成暂停第8轮、重启哈希一致、继续到60轮，四局240轮；另完成神经策略/规则五轮对照两局。参数越界被拒绝，跨批次比较与两种无损JSON导出通过。恢复备份后7个批次、432个JSON文件、主实验状态及原费用账一致。最终证据位于runs/stage28-release，源代码和验收摘要冻结于releases/local-market-v14.0.0。

验收发现并修复两项问题：中断免费批次部分文件为全零，写入增加flush/fsync，旧文件完整保存在recovery-evidence，并明确重新计算免费批次；这不是恢复已损坏内容。付费批次禁止该重算路径。导出曾经因浏览器JSON解析而舍入64位随机数，现改为原始响应文本/Blob，实际下载逐项比对完全一致。

本轮新增180次真实请求。长局中1次豆包政府响应违反严格格式；已保留费用并记录失败，审阅后额外尝试一次成功。原失败文本在旧异常路径中未保存，不能补造；该缺陷已修复，后续格式错误会保存原文和用量。默认恢复不重试；只有已完成的格式失败允许明确操作一次，网络结果未知时禁止自动重试。

原10元预算未提高。累计保守保留9.938022元，剩余0.061978元；根据可用用量和历史估算合计约1.270500元，**这不是供应商最终账单**。失败及未知风险预留不自动退还。标准完整上下文调用需要0.42元预留，因此现在余额不足以继续该模式；免费规则、共同学习和训练策略不受影响。

豆包按官方分档价格核算，紧凑请求使用向上取整的1/4微元每token上界，完整请求使用跨档2/11上界且保留0.42元。DeepSeek采用3/9上界。价格快照有效至2026-09-08，过期后停止新付费请求。官方来源：[火山方舟价格](https://www.volcengine.com/docs/84458/1585097?lang=zh&redirect=1)、[DeepSeek价格](https://api-docs.deepseek.com/zh-cn/quick_start/pricing/)。

## 使用与数据

市场交互及高级通信使用原协调器；四方批量工作台使用可行选项协议。二者都真实结算，但协议不同，不能把紧凑选项实验称为无约束自然语言自博弈。

本版数据目录 .local-state-v14-release；工作台数据在其 workbench 子目录。原 .local-state、各阶段 .local-state-v14* 和旧冻结发布件保留。原历史费用账仍固定使用 .local-state/model-budget.sqlite3，恢复任何版本都不得回滚。

工作台中已导入三批通过验收的长局（规则、豆包、DeepSeek），可以勾选跨批次比较和导出原始模型/回合轨迹。导入是已完成记录，不会重新调用模型。

备份包含普通存档、队列数据库和逐轮日记。先暂停排队/运行中的任务；恢复需先停止服务。旧数据先保留副本，再验证并恢复。

## 明确的模型边界

这是合成、有限策略集合的研究市场，不是已标定的现实经济预测器。消费者返还是成交后净支出返还，未引入家庭储蓄或跨期收入；合同是限期锁价/优先供给预留，短订会终止，不是无限履约担保或完整法律合同。

未提供与目标市场对应的真实消费者选择、成本、供给和外部性数据，因此没有伪称完成现实校准。现实应用需另外识别需求/支付意愿、供给可靠性、成本及福利权重，并在独立现实样本中检验。工资就业、家庭/银行、一般均衡、税收环境扩展和多人公网仍不属于本次约定的单人首版范围。

工程验收、真实模型能否调用、策略是否收益更高、现实是否有效，是四个不同结论。本版提供前三项的明确证据及负结果，不承诺现实有效性。
