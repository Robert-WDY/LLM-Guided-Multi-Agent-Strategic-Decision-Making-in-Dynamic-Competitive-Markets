# v16 目标驱动博弈建议：六阶段验收约定

沿用本机单用户、原市场配置和原10元账。v15.0.1冻结包不覆盖。建议为有限预算下的候选策略搜索，不声称完整动态市场全局最优。

1. 目标与阶段：公司阶段目标、利润、福利、平衡/自定义权重；硬约束、版本化固定尺度、解释分解。独立合成决策表验证目标切换和现金约束。
2. 市场与预测：合法观察构造预测状态，真实MarketEnv跨期结算，企业/消费者/供应商/政府异质响应；机制能力与未建模假设披露。独立引擎对照和隐藏状态不变性。
3. 动作与搜索：价格/投资/采购/合同/合作组合、合法归一化去重、局部候选扩展、训练与独立验证情景、步数硬预算。小空间穷举对照、动作可执行、预算与留出验证。
4. 博弈诊断：多人迭代最佳回应与各角色偏离、联合福利协调方案及参与激励、公共品退出诱因、局部囚徒/协调结构；不完全检查明确标记。已知人工博弈独立解和2/5/10公司实际市场实验。
5. 证据界面：事实/预测/假设/有限范围数学检验，目标分解、替代方案、失效条件、机制覆盖、搜索边界；保存/导出、复跑及实际市场执行实验。
6. 独立留出：开发与留出种子分离，机制/人数/阶段/目标变化，建议与基线配对执行、预测误差/下行/耗时/重放、全量测试/浏览器/备份恢复和冻结。

公司福利目标是该公司单边可执行建议；研究者联合福利方案单独标识，不假定其他主体会接受。对手目标属于假设。预算耗尽时返回已评估结果与检查覆盖，不制造误差上界。尾部风险为样本内指标，禁止称为现实保证。不会追加真实模型费用；复核原有响应不能替代新算法的真实模型有效性证据。
