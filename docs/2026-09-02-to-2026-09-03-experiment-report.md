# 2026-09-02 至 2026-09-03 实验整理报告

## 一、两天工作的核心主线

这两天没有继续无边界增加市场功能，而是沿着一条可以逐层判错的研究路径推进：

```text
经典 Cournot 真值基准
→ 证明精确建议能否改善真实 LLM 决策
→ 拆分合作背离中的收益、提示词和模型差异
→ 进入重复 Cournot 与真实对手闭环
→ 验证信誉、承诺、履约和公共韧性完整链路
→ 回到原生复杂市场做零 Token 门禁
→ 检查市场、合作激励、Persona、Belief、Opponent Model 和 Advisor 是否值得继续付费
```

最终结论不是“所有模块都已有效”，而是已经清楚区分：

- 经典博弈中的精确 Advisor 有效；
- 原生复杂市场 Advisor 尚未稳定；
- Agent 的合作或背离同时受到收益结构、提示框架、人格和模型提供方影响；
- 市场确实支持公共品、搭便车和集体行动失败，但当前单家公司合作的私人激励偏弱；
- Persona 数学层有明显作用；Belief 和 Opponent Model 会改变决策，但预测与长期收益尚未稳定对齐。

## 三、9月2日：经典博弈与真实 LLM

### 1. Canonical Cournot 单轮基准

#### 目的

原生市场太复杂，没有解析最优动作。先在经典 Cournot 中验证 Advisor 的数学、信息边界、建议传递和真实模型采纳是否正确。

#### 设计

- 需求：`P(Q)=max(30-Q, 0)`；
- 边际成本：6；
- 双方整数产量：0–30；
- 精确结果：Cournot-Nash `(8,8)`，对称合谋 `(6,6)`，Stackelberg `(12,6)`；
- 3 个对手预测产量 `{6,8,12}` × 2 条件 × 2 模型 × 3 次重复；
- 共 36 次真实模型决策。

#### 结果

| 条件 | 样本 | 平均遗憾 | 零遗憾率 | 平均利润 | 建议采纳率 |
|---|---:|---:|---:|---:|---:|
| Persona Only | 18 | 3.1111 | 55.56% | 57.2222 | — |
| Exact Advisor | 18 | 0 | 100% | 60.3333 | 100% |

18 个配对为 8 正、10 平、0 负。结果证明：当候选空间、收益函数和对手分布正确时，真实 LLM 可以采纳精确建议并消除 Best Response Regret。它不能证明原生动态市场的 Pareto Advisor 已经有效。

### 2. 合作背离：是提示词还是收益驱动

#### 设计

把三个因素分开：

1. 提示是否明确出现“履约/部分履约/背离”；
2. 贡献的私人经济回报是正还是负；
3. 是否保留长期 Balanced 人格语义。

增加 `neutral_numeric_v1` 中性提示，并在因果实验中隐藏 `commitment_honesty`、`opportunism` 等直接泄露合作倾向的字段。零 Token 穷举确认：高背离诱因下最优贡献为 0，低背离诱因下最优贡献为 10。

#### 三组真实结果

- 重复市场语境 24 次：模型经常虚构题目未定义的未来声誉收益，不能干净识别私人最优；
- 严格终局 + Balanced 12 次：豆包两种提示均选择 0，DeepSeek 两种提示均选择 10；
- 严格终局 + 纯利润目标 12 次：豆包显式/中性均为 `0,0,0`；DeepSeek 显式为 `0,0,0`，中性为 `10,10,10`。

结论：豆包能够在没有“背离”字样时从收益公式自行发现搭便车；DeepSeek 的经济最优背离明显受到显式选项提示影响。当前系统没有跨代训练或权重演化，因此应称为“收益驱动决策”或“上下文内适应”，不能称为 Agent 自我演化。

### 3. 重复 Cournot 10轮闭环

#### 设计

- 3 个新协议 Seed；
- Persona Only vs Exact Online Advisor；
- 对手分别为固定 Nash、上一轮历史最优反应、真实 DeepSeek；
- 共 18 个 Episode、180 个结算回合；
- 所有 Agent 在同轮动作生成前冻结上下文，不泄露对手本轮动作。

#### 结果

| 对手 | 配对 | 平均利润增量 | 平均遗憾降低 | 利润正/平/负 |
|---|---:|---:|---:|---:|
| 固定 Nash | 3 | +13.67 | 13.67 | 2/1/0 |
| 历史最优反应 | 3 | 0 | 5.67 | 0/3/0 |
| 真实 DeepSeek | 3 | +194.33 | 122.67 | 3/0/0 |
| 总体 | 9 | +69.33 | 47.33 | 5/4/0 |

真实 DeepSeek 条件下，Advisor 使竞争从过量生产向 Cournot-Nash 靠近，提高了焦点公司利润，但平均价格上升 2.53、消费者剩余×2下降 1,023.33、总福利×2下降 192.67。由此得到一个重要研究结论：私人战略建议有效，不代表市场社会效果更好。

运行中两次模型输出截断或带多余 JSON。系统先原子保存 Provider 结果，再拒绝结算，只恢复未完成 Episode，没有重跑已完成样本。这验证了真实实验恢复和审计链路。

### 4. 信誉、报复和宽恕

第一次运行发现 v4 市场虽开启合作，但 Persona Capability 仍是 `cooperation=false`。直接修改 v4 会导致历史 Advice Hash Replay 失败，因此撤销原地修改，使用可审计覆盖并最终发布 v5。

修正后，同一市场状态和提议只改变合作历史：

| 模型 | 无历史 | 近期背叛 | 背叛后修复 |
|---|---|---|---|
| 豆包 | 3/3接受 | 3/3接受 | 3/3接受 |
| DeepSeek | 3/3接受 | 3/3拒绝 | 2接受、1忽略 |

DeepSeek 出现明确报复和部分宽恕；豆包虽在理由中引用信誉，但动作不变。这说明“模型提到某信息”不能作为“信息进入决策”的证据。

### 5. Cooperation v5 真实完整链路

#### 链路

```text
Proposal → Acceptance → Commitment
→ 目标轮 Actual Contribution
→ 市场扣款和公共韧性更新
→ Fulfillment/Betrayal Verification
→ Credibility Update
```

第一次运行中豆包原始动作请求全额贡献，但错误引用历史 message_id，被安全校验拒绝，回退为 0，最终被账本记为背叛。这不是自主背叛，而是“非法动作→安全回退→最终贡献0”。DeepSeek 还出现自由文本反提议 80 万、结构化字段却接受原 100 万的冲突。

修复提示边界后，相同 2 个模型 × 3 Seed 的正式结果为：

- 6/6 接受；
- 6/6 全额贡献 100 万；
- 6/6 验证为 fulfilled；
- 12/12 真实生成边界成功；
- Schema Repair、非法动作和 Replay 失败均为 0；
- 可信度从 50% 更新为 75%。

它证明生产闭环正确，不证明 Agent 永不背叛，也不证明合作已经自我演化。

## 四、9月2日至3日：原生市场零 Token 门禁

### 1. 市场与消费者模型

20 Seed × 4 市场模型，共 80 个配对单元，另运行 200 个动态回合：

- 80/80：降价提高焦点潜在需求、提价降低需求；
- 80/80：广告提高认知、服务提高质量；
- 80/80：100 万产能投资按配置精确形成下一轮 100 单产能；
- 80/80：私人韧性投入提高私人韧性；
- 需求、份额、利润、现金全部闭合；
- 没有出现四家公司份额同时严格上升或同时严格下降。

结论是市场基本方程和会计方向正确，但参数还没有现实数据校准。

### 2. 公共韧性和搭便车

20 个新 Seed、10 轮持续高供应冲击：

- 搭便车者平均获得 30,089,398 分公共保护；
- 搭便车者相对三名贡献者平均多赚 5,664,309 分；
- 少一名贡献者使最终行业韧性下降 131,941 PPM；
- 全员不贡献使韧性下降 725,693 PPM、缺货增加 10,672.05 单、市场利润减少 124,008,204 分；
- 搭便车者相对“自己也贡献”平均少赚 764,478 分。

这说明搭便车者具有相对竞争优势，但在长期高风险环境中未必提高自身绝对收益；全员都搭便车则产生集体行动失败。

### 3. 原生合作私人 ROI 门禁

对 100 万贡献做 20 Seed、未来 3 轮反事实，覆盖正常/强灾害、有/无其他三家公司贡献四种条件。四格全部为 20/20 负值；最有利的强灾害、无其他贡献条件均值仍为 -379,679 分。

因此当前市场缺少一个私人回报为正、一个为负的合作处理。真实 LLM 合作诱因实验没有启动，避免把偏弱的市场激励误判为模型不合作。

### 4. Advisor v7 与 v8

v7 的 5 Seed、20轮探索共有 300 个窗口，放行 27 次：22 正、5 负，覆盖率 9%，最坏 -262,043 分。说明延长回合本身不能解决建议风险。

v8 在开发集冻结公开信息执行门禁：300 窗口放行 37 次，37 正0负。随后不再调参，直接进入 10 个未见 Seed、600 窗口：

- 放行 77 次，覆盖率 12.83%；
- 67 正、10 负；
- 放行均值 +694,550 分；
- 最坏样本 -327,970 分；
- 最坏 Seed×Persona 分组均值 -16,280 分。

总体均值为正但尾部失败，v8 未晋级，未启动真实 LLM Advisor 扩样。结果表明问题不只是阈值，公开预测状态和候选排序仍有系统误差。

## 五、9月3日：Persona、Belief、Opponent 与完全信息

### 1. 10 Seed 战略消融

10 Seed × 3 人格 × 已知/混合/未见对手池，共 90 个匹配单元、5轮：

| 模块增量 | 平均企业价值变化 | 正/平/负 | 最坏配对 | 单步遗憾变化 | 晋级 |
|---|---:|---:|---:|---:|---|
| Persona Planner vs Rule | +3,049,027 | 85/0/5 | -2,241,687 | +266,484 | 否 |
| Belief vs Persona | -481,859 | 25/25/40 | -5,131,486 | -127,118 | 否 |
| Opponent v1 vs Belief | +330,886 | 40/32/18 | -3,802,072 | +109,934 | 否 |
| Opponent v2 vs v1 | -116,387 | 0/76/14 | -1,758,016 | -24,205 | 否 |

解释：

- Persona Planner 有强平均价值，但有负尾部，而且单步遗憾与长期价值不一致；
- Belief 降低单步遗憾，却降低长期企业价值，说明优化目标错位；
- Opponent v1 在已知对手池较有效，进入混合和未见对手后明显退化；
- Opponent v2 没有正样本，不能晋级。

长轮次预跑还发现遗憾函数用候选标签跨预测状态和真实状态查找，边界去重后会报错。现已改为直接结算 Agent 实际选择的动作，并同步修复 Stage 6.3 调用点和回归测试。

### 2. Belief 真实证据复核

此前 36 次豆包调用显示：固定状态中 OFF 明确引用率 0/3、ON 为 3/3，3/3 动作改变；多轮利润 2正1负。但预测 Accuracy 仅 44.44%，Brier 0.6631，Log Loss 1.0694，只略好于均匀随机基线。

因此可以说 LLM 会读取 Belief，不能说 Belief 已改善长期收益。本轮没有重复付费。

### 3. Persona 真实证据复核

P1 的 22 次真实决策表明，在相同财务压力状态中，结构化效用权重比人格标签、目标文本和 traits 更能稳定驱动投入。P2 的 20 次真实决策显示人格方向确实不同，但极端激进人格出现过度投入、累计利润 -12,041,283 分。这说明“符合人格方向”和“在该人格目标下真正优秀”必须分开评价。

### 4. 单一 Agent 完全信息

10 Seed × 5人格 × 2条件，共 100 个 Episode、1,000 次 Mock 决策。信息隔离、公司级观察和 Replay 全部通过，但 Mock 策略不读取新增信息，所以企业价值、利润、份额和名次处理效应均为 0，公开/特权第一名率同为 6%。

此前豆包已完成的三种人格在完全信息下企业价值两正一负，3/3 仍为第四名。强命题“只给完全信息，不管人格都能第一”已被否定。后续应测试“完整信息 + 状态比较摘要”和“完整信息 + 反事实决策器”，不能把这些能力的效果归因给信息本身。

## 七、这两天真正证明了什么

### 已经有较强证据

1. 精确、可验证的博弈建议能改善真实 LLM 的单轮和重复 Cournot 决策。
2. 私人利润改善可能以消费者剩余和社会福利下降为代价。
3. 合作背离不是单一来源：收益、提示词、人格和模型提供方都会改变行为。
4. Proposal、Acceptance、Commitment、Actual Contribution、Verification、Credibility 已形成可重放的生产闭环。
5. 市场支持公共韧性、搭便车和集体行动失败。
6. Persona 数学层能稳定影响策略方向，并具有较强平均收益。
7. Belief 和 Opponent Model 确实会进入决策，但当前质量不足以稳定提高长期价值。

### 仍不能声称

1. 不能声称原生复杂市场 Advisor 已经稳定有效。
2. 不能声称 Agent 的合作或背离是“自我演化”。
3. 不能声称完整信息自动形成竞争优势。
4. 不能声称 Persona 方向一致就代表决策质量高。
5. 不能声称当前市场参数已经通过现实数据校准。
6. 不能声称 DeepSeek 和豆包在信誉、承诺和效用遵循上具有相同行为。

## 八、下一步建议

按优先级只做三件事：

1. **合作 ROI 修复**：增加公司级合作收益归因，构造一个私人合作回报为正、一个为负的可识别处理，然后再做最小真实 LLM 合作实验。
2. **Advisor 预测修复**：不要继续在 Holdout 上调阈值，改进公开状态预测和候选动作排序；在新的未见 Seed 上消除负尾部后再付费。
3. **Belief/Opponent 校准**：从简单动作频率升级为策略分布，使用 Brier、Log Loss 和长期企业价值三重门禁。

在上述零 Token 门禁通过后，每个方向先做 `2 模型 × 3 Seed` 的最小真实验证，不直接扩大到大规模 Self-play。
