# v17修补验收约定（实验前）

针对v16七项不足，保留旧算法和冻结包。目标不是宣称全局或现实证明，而是补齐可实现的算法与证据缺口。收费调用保持原10元累计约束。

1. 公开历史的带遗忘价格变化后验，逐时点预测误差、样本量和冷启动披露；只使用决策前公开价格，拒绝未来/乱序数据。用已知稳定/转向序列独立验证学习和校准。
2. 扩展价格、投入、采购、合同与伙伴的组合/局部搜索；在有限小网格上穷举核对。针对每个入围建议让其他角色重新寻找私利最佳回应，比较反击后的收益再推荐；预算不够完整反击检查则弃权回基线。已知反击博弈验证选择改变。
3. 所有公司同时启用建议，共享同一回合之前信息，落盘历史并验证暂停恢复；2/5/10家公司的10轮/20轮实验。不能把单方实验当作共同适应。
4. 每次报告目标权重扰动的选择稳定性和帕累托支配；评估阶段/期限敏感性。保留用户目标，不自动把权重学成只对验收有利的值。
5. 固定32个新独立种子，正常/低供应商现金/低政府现金分别配对；v16、v17及加大预算搜索对照，按种子汇总bootstrap区间、负收益比例、预测相对误差和下行，禁止按结果删负样本。强基线及机制压力不能与种子混淆。
6. 独立纯算术审计结算恒等式，加上可穷举的小博弈求解器做差分核验，验证篡改能被发现；这不能替代整个经济引擎的外部实现或现实数据校准。全量回归、界面、存储及独立冻结。

各阶段有单独JSON证据，代码错误修复保留失败记录；留出后不按收益修改策略。无法证明的现实有效性、样本外绝对安全和无限动作全局最优明确保留为边界。
