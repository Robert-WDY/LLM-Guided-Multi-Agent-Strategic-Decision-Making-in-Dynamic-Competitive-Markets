# 竞争性定价中，何时值得改变 Agent 的原报价？

**投稿定位。** 定价建议、按案例在人与机器之间分配报价、允许随时弃权、让对手响应反事实动作，均有直接前作。本项目可检验一个更窄、能被数据推翻的命题：当经营 Agent 已经报出一个可执行价格时，另一个只能使用限定历史信息的建议器，能否在结果揭晓前挑出值得修改的报价，并在对手继续行动后提高该企业的终局利润？两种模拟市场、不同信息权限和真实模型草稿提供了比较条件。已完成的严格报价历史实验未能确认相对原草稿的正增益；放行风险也未通过预定门槛。这个诊断结果本身可报告。[实验设计](../experiment-specs/public-price-value-v1/PLAN.md) · [配对结果与范围](public-price-value-stage.md)

## 竞争者反应、反事实和信息权限

**基准与对手建模已有正结果。** EconEvals 明确区分单一经营者的多产品动态定价、双寡头的竞争倾向测量。Fish、Gonczarowski 与 Shorrer 报告 LLM 寡头卖方可快速形成高于竞争基准的价格，提示措辞会改变程度。Liu 等在反复买卖谈判和资源交换中，使用历史拟合对手并模拟候选消息，获得优于多种基线的收益。这些结果支持把对手模型列入比较；本项目将其与同草稿、同候选、同预算的无条件预测直接配对，估计的是条件建模本身是否改变选价并创造增量利润。[EconEvals](https://arxiv.org/html/2503.18825v4) · [Fish 等](https://arxiv.org/abs/2404.00806) · [Liu 等](https://arxiv.org/html/2602.19309v2)

**固定价格路径与冻结对手学习是两种干预。** Bichler 等（2026 年 10 月预印本）发现 LLM 对常见在线学习器的优势在面对全信息学习器时大为缩小。他们明确指出，沿已实现对手轨迹计算的外部遗憾无法衡量对手会随替代策略行动时的策略遗憾。Malafeev（2026 年 7 月 SSRN 工作论文）已在差异化双寡头上成对比较同一 DQN 进入者面对冻结 Q 学习更新或恢复更新的老对手，十个配对中恢复更新时进入者利润均下降。冻结 Q 参数的对手仍可对状态作出不同报价。本项目重放的是保留草稿世界中**整条已实现的对手报价**，因此阻断的是报价响应渠道；比较的是这一渠道对相同一次价格修改的增量效果。策略遗憾对自适应对手的处理在 ICML 2012 已有理论定义。[Bichler 等，第 3 节及补充材料](https://arxiv.org/html/2610.21711v1) · [Malafeev](https://doi.org/10.2139/ssrn.6990419) · [Arora、Dekel 与 Tewari](https://arxiv.org/abs/1206.6400) · [本项目报价重放协议](../experiment-specs/public-price-value-v1/RIVAL-REPLAY.md)

**价格可预测，仍需独立检验调价收益。** Bertsimas 与 Kallus 研究历史价格和需求存在内生性时，用预测需求定价的次优界与因果最优性检验。他们既指出识别限制，也说明预测偏差在某些结构下仍可能容许良好的决策。Light 与 Wang 的竞争动态定价模型进一步表明，在其假设下，当竞争者同步试价且部分对手报价不可见时，遗漏变量可导致看似系统性的价格共变。Fisher、Gallino 与 Li 在零售现场则通过价格实验及缺货信息识别替代效应，其算法提高了实验商品类别收入。三者分别研究预测决策质量、策略学习和现实需求识别。用本项目的公开历史可估计下一期误差；验证改价是否赚钱，需要实际运行各模拟分支或取得足以识别该效应的现场设计。[Bertsimas 与 Kallus](https://doi.org/10.1287/ijoo.2022.0077) · [Light 与 Wang](https://arxiv.org/abs/2602.12888) · [Fisher、Gallino 与 Li](https://doi.org/10.1287/mnsc.2017.2753) · [本项目预测与干预结果](public-forecast-stage.md)

## 本项目能够识别的增量

在预排时点记录草稿，令每个候选价格按同一合同执行四轮，之后各经营者依据各自真实反馈继续经营到终局。令 Δ 为候选分支减保留草稿分支的累计折现利润，G 为候选结算前已冻结规则的放行决定（0 或 1）。三个数需各自报告。[配对设计与信息字段](../experiment-specs/public-price-value-v1/PLAN.md)

| 估计量 | 解释与对照 |
|---|---|
| 全部机会的平均 GΔ | 给全部预定机会部署该建议策略的收益。弃权时增量为零。比较保留草稿、固定涨跌、等预算无条件建议及同覆盖率随机放行。 |
| 放行中 Δ＜0 的比例，弃权中 Δ＞0 的比例 | 第一项衡量实际放行的损失风险，第二项衡量错过的获利候选。两项分母分别为放行数和弃权数，并列报告覆盖率和金额。拒绝的候选也须真实运行模拟分支，才能评估第二项。 |
| 同方向调价的 Δ（实时响应）减 Δ（重放报价） | 比较保留对手反馈与阻断反馈时的利润增量。这个量可以很大，而条件建议器仍与无条件建议器选择同一动作。还需比较两建议器的动作分歧及执行价值，才能判断模型是否利用了对手反应。 |

严格公开报价的建议层只读双方历史报价、当前草稿和轮次；经营 Agent 可读取己方经营反馈。另一个原生实验允许建议层看到己方经营信息，其规则草稿的折现收益在独立种子上重复改善，但相对固定涨价或同覆盖率随机放行的优势未得到确认。两类结果同时保留，可以把“某个复合建议器能赚钱”与“指定信息、对手模型或弃权规则提供增量”分别落在可核查的对照上。这里只有一次预排干预及随后的路径，真实模型也只在模拟企业中运行。独立经营者、真实交易利润、长期反复建议和竞争均衡仍需独立证据。[严格报价结果与原生独立复验](public-price-value-stage.md) · [原生复验设计](../experiment-specs/public-price-value-v1/REPLICATION.md)
