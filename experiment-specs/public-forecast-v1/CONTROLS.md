# 确认前补充对照

开发集生鲜完整模型强于无额外字段的模型。冻结后另以同样学习器、同样训练数据分别去掉缺货字段、去掉价格约束字段及仅添加聚合需求组，测量下一期绝对误差的增量。为区分归因器从数据本身和从预测误差中获得的信号，用持续值的误差替换已拟合预测误差，训练相同的分类器。控制实际误报的阈值取 32 个稳定校准种子各自整局最大非稳定报警分数的第 90 百分位上侧观测值。本阈值用于评价，无报警包含不确定，不能解释为已证实稳定。

另用 78200–78231 的新规则种子检验弱需求变化（标准强度三分之一）、需求与对手同时变化及稳定安慰剂。主分类器三分类，联合变化记录其实际输出，不把任一单标签算作正确识别两种因素。真实确认路径在机会到达时、分支结算前将三种分数、事前八轮精度及放行决定写入单独日志。主单位始终为种子；稳定及每种变化同时报告，反向对手不参与任何开发与校准。
