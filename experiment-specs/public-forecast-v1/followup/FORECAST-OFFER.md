# 第二个真实终局对照

首个确认中候选沿用旧建议器，因而额外检验预测器自己选方向的情形。冻结代码及诊断阈值后用 79200–79231，每市场每提供方 32 个新种子。四种情境、调价日程、输入、四轮承诺和终局回交方式与第一批一致。允许的两个候选为真实草稿上下各 4%，受已知己价范围约束。以预测下一轮销量乘以根据历史成交估计的单位利润，从中挑选预计增益最大的不同可执行价格。实际两条路径均运行至第 60 轮，包括建议被拒、估计增益为负的情况。若两个方向均无法执行则保留草稿。

归一化评分为预计边际利润除以近期销量预测绝对误差对应的利润量级，分母下限为近期绝对利润的 2%。用旧独立校准来源态的评分第 75 百分位与 0 的较大值作阈值，不以未曾执行的替代候选冒充已知标签。预定义诊断门还要求过去八个已结算预测的两项目标都优于持续值。与全部采纳、仅用预测选择正收益以及始终保留做比较。单独评估能否达到同样的独立收益下界、覆盖和风险上界。两批真实样本独立，不跨批合并选优。
