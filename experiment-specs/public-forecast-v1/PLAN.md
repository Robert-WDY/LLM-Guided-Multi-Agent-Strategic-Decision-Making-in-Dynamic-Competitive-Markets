# 公开预测、变化归因与终局机会

预测对象是下一轮焦点企业实际售出量和同轮对手公开执行价。直接沿用最近已结算值为主对照。预测时知道本轮自己的报价及可申请的合法价范围，不知道本轮同时报价、销量、缺货、需求参数或对手类型。原生额外字段为上轮公开需求和缺货、上轮自己的申请与执行价差及当前己价合法范围。对比去掉这些额外字段的模型。按市场分别报告 MAE、相对减幅与种子簇 95% 配对区间。

沿用上一阶段的两个 60 轮市场，预热六轮，其后每份价约四轮。隐藏变化在 15–39 轮事先随机选定，方向与来源独立；稳定、需求变化、对手换策为三类。确认加入训练未见的反向报价对手，归为换策类。归因仅使用已结算信号。报告全期误报、变化后第 1/4/8 个结算的混淆矩阵和稳定孪生对照。区分来源不等于识别现实因果。

规则种子按训练 71200–71263、开发 72200–72223、校准 73200–73231、确认 74200–74263 划分。真实模型用 75200–75223 训练、76200–76215 校准、77200–77247 确认，每种子两模型、两市场，每局有一次独立安排的第 23–43 轮机会。沿用上一阶段修正单位的同一候选生成器。两条分支分别执行四轮原草稿或提案，随后都把控制交还同一真实模型，根据各自反馈运行至第 60 轮。拒绝机会也结算。全程复用原 50 元共享账本，起始编号 12460，历史保守占用 23.808940 元。

终局机会比较既有草稿/候选特征，与增加预测结果、既往样本外相对误差及变化归因的分数；另直接检验“此前预测胜过沿用上轮”规则。禁止以当前尚未结算的预测误差放行。诊断阈值用独立校准集第 75 百分位。严格门从校准第 50/75/90 百分位筛选，要求覆盖至少 10%、配对终局收益区间下界为正、干预种子中任一模型受损比例不超过 10%；确认时要求风险单侧 95% 上界不超过 10%。相同市场的两个模型归入同一种子簇。真实确认前冻结预测器、归因器、分数与阈值。生产定价只在证据满足条件后考虑接管。
