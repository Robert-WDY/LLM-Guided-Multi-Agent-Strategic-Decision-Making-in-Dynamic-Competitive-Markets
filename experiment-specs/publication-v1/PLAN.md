# 论文定位与公开信息价值的预先设计

本轮以同历史对照回答“可见历史究竟缺少有价值的信息，还是现有算法没有把信息转成收益”。不调整上阶段已经冻结的建议器。原先用户授权的总模型账上限 50 元；本轮开始余额 0.670584 元。

1. 两个市场各 128 个训练种子 101000–101127、64 个校准种子 102000–102063、192 个未见检验种子 103000–103191。市场共享种子编号，分别报告。原规则 Agent 生成预热与草稿，在种子决定的第 23–43 轮同时复制同一市场。决策后的第二轮开始，对手进入原市场的跟随/压价规则或反向规则；两个分支以等概率作为实验分布。首轮结算逐项必须相同。分别持有原草稿、降 4%、涨 4% 四轮，再各自依新历史定价至第 60 轮。所有收益均相对同一世界保留草稿；.99 折现为主，未折现为敏感性。市场种类、时点、草稿可见，未来类型、评价随机数和收益标签对历史策略保密。
2. 对每个种子，分别求“知道种子内所有潜在收益但不知道下一类型”的三选一上界与“还知道下一类型”的上界，其差是该受控实验的完美类型信息价值。两者都享有实际建议器没有的事后收益表。另求 75% 准确的类型信号对应上界。报告是否存在同一来源下最优动作集合不相交、同一调价在两种世界反号以及可改价但无法在两个世界都严格获利的比例。若复制同一世界当作两种类型，信息增益应精确为零。
3. 可执行比较使用同一个每市场 ExtraTrees（128 棵、最小叶子 8、固定随机数），预测动作增量利润。输入为冻结的公开报价通用特征、候选和假设类型，不含真参数；信号仅在明确披露的处理组可用。对同一组预测分别按 50%、75%、100% 信号准确率加权选动作，可选择保留。用固定在独立校准样本的预测分数 75 分位、至少零作为另一个弃权门；比较固定动作、此前冻结的历史门和同覆盖率随机放行。标签只用于训练、评价。预先将每市场“完美信号的可执行相对无信号策略”以及“完美信息上界差”设为四项主要比较，分别报告按种子自举 98.75% 区间（Bonferroni 家族 5%）与常规 95% 区间。其余含风险与亚组均属诊断。
4. 另对旧外部 40 种子、两供应商、共 80 条三方向真实决策作回顾性迁移检验。固定既有报价建议器，不重拟合；用正确方向归属，按种子聚类，单列结果。用原 50 元余额优先补做原生生鲜 8 个独立真实模型种子 105000–105007，按已冻结选择器事前封存，分别保留、涨、降至第 60 轮。两供应商各四个，四种环境平衡。两批不混合，不依结果补样。共享总账预算不足或提供商故障时只披露完整样本及缺失原因。
5. 投稿结论以可复算、匹配信息与预算、对照强度和样本精度为准。规则环境的公开标签是受控信息处理，本设计没有在真实业务中观测或预测出这些标签。任何没有通过的主张均如实报告。
