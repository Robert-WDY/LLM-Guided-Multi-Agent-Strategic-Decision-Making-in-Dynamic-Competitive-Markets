# 数字报价下可选停止的迁移核查

三档经营模型的外部隐藏时点组出现相对即刻决定的正收益，但两模型的外部菜单行为相同。为核查这一发现，使用已规划的数字报价独立批次中每模型每市场按顺序的前 64 个种子，冻结规则经营者训练的停止器，不新增挑选标准。本分析和数字报价主确认共享种子，单列为追加迁移证据。经营模型不知道变化是否或何时出现，评估者沿用该数字批次已生成的市场变化日历（其中有变化时为第15–39轮；首次可决定窗口仍是第19轮）。只沿原计划轨迹依序形成停止决定，之后比较自主停止、首机会即决、固定再等四轮、首机会固定降4%、固定涨4%、全程保留。所有方案从第1轮折现到第60轮；不同路径的经营模型都直接输入自己的最近四轮数字并重新报价。无变化计入分母。估计范围是固定策略迁移，不作第二次独立确证。
