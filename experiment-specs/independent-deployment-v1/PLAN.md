# 独立确认、未知时点与现场证据

在读取本批终局结果前设定。部署门槛是研究方的显式经济假设，非企业签署的报价。单位为每个预定机会的 .99 折现至第60轮的额外利润，EconEvals 为 5 基准单位，生鲜为 20,000 模拟元。采纳亏损风险目标为 ≤10%。这些沿用上一阶段功效示例及既定损失门槛；另报不折现、损失最差 5% 的均值、覆盖和保留时错过收益。若以单侧同时下界超过门槛、放行损失率单侧上界 ≤10%、覆盖 ≥10% 才判可部署。若上界低于门槛可排除预定幅度，否则记不确定。

**独立真实语言模型。** 锁定 Qwen2.5-0.5B-Instruct Q4_K_M（官方 GGUF 339217f5db79a29953eb74d5343926648285ec7e67）与 SmolLM2-1.7B-Instruct Q4_K_M（官方 GGUF 2d4a76a30b4af41ecd395c35725ac11688d4cfe4），开发训练/校准均未用这两份权重。策略为上阶段冻结的 delayed.inferred；同预算对照是 delayed.uniform，另有固定涨跌与保留。市场仍为模拟市场。每个经营周期由 LLM 在反馈草稿的 −4%、原值、+4% 三档中形成其报价，下一周期继续依自己分支的最新结算独立生成。三个动作的含义和市场反馈摘要在两模型间一致；输入为本企业相对对手报价、销量趋势、利润趋势、剩余时间段与市场类别的有限编码。对每个**完整相同**的提示词使用真实贪心推理及缓存，留存每个输入和实际输出；独立统计单位是市场种子，非推理调用。此合同覆盖有限菜单的真实模型经营 Agent，自由文本草稿、其他模型能力等级不能由此自动外推。若某模型行动不随反馈改变，如实按预定样本报告。模拟一次四轮调价，按种子随机指定第 23–43 轮的一个可执行窗口，之后恢复各自的 LLM 草稿到终局。稳定、需求、跟随/压价、反向四种环境平衡，每个市场在同一种子上配对两个模型但分别分析。外部种子 121000–121191，每模型 192；生鲜 122000–126607，每模型 4608。既有外部配对标准差 19.29，生鲜较大试点 432,134；以四项单侧族错误率 5%（每项 .0125）、80% 功效，若真均值比部署门槛再高一个门槛，所需约 142、4,440 个独立种子。预定数量向上取整。模拟利润尾部可能使实际精度偏离计划。用固定随机数种子配对自举，报告单侧 98.75% 界及普通 95% 区间，不能按结果加样。保持商业 API 原 50 元上限，本轮使用本地推理。

**未知切换时点。** 另用每市场 384 个训练种子 130000–130383、512 个独立确认种子 131000–131511。无变化、需求冲击、对手跟随/压价、对手反向等量；有变化时首次生效在第 8–53 轮内，由独立散列抽取，窗口和变化标签只对评估器可见。经营 Agent 沿用现有反馈控制。每第 19、23、27、31、35、39、43、47 轮允许建议器依据当前和既往已结算公开报价、草稿和时钟，立即涨/降 4% 持续四轮、再观察四轮、或永久弃权。只允许一次干预。用训练种子的三种潜在终局估计当期候选价值，向后递推下一机会价值，按种子交叉拟合下期决策。无论何时干预，都从第 1 轮核算整局利润，保留直到期末按零增量计。比较首机会必须作决定（可弃权）、固定再等四轮（可弃权）、学得的等待/调价/退出、全程保留。主要两个比较为动态策略相对首机会决定，各市场 97.5% 配对区间。报告立即/等待/永不介入、冲击前干预、无变化时行动、延迟、错过的增益、终局上界。策略输入不得出现种子、类型或真实切换轮。用隐藏标签置换及相同公开前缀检查、分支回放和首日起算恒等式验收。

**现场部分。** 检查能否取得本系统实际被展示、企业自主采纳、净交易利润和竞争暴露数据。若没有上述实际交易和授权，不得伪造现场样本或将他人项目归因于本系统。交付可执行的分配、分析及回放验证，将外部对照证据和本系统的实际现场状态单列。
