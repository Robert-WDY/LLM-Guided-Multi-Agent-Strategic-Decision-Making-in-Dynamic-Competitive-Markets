# 直接数字报价的独立补充

在只检查两模型三档菜单的 162 个推理输出、尚未读取本批利润结果时，发现 Qwen 全部选择 C、SmolLM 161 次选择 C。保留原确认，不据此重选模型。另开外部 140000–140191、生鲜 141000–141191，每市场每模型 192 个独立机会；主结果单列。本补充对原先 ±5 与 20,000 部署门槛沿用同样推断，生鲜另外明确是否有足够精度。两份原锁定权重使用完整数值提示，告知实际可执行区间、反馈参考价、最近 4 轮己方执行价、对手公开价、自己销量和利润、剩余轮数。要求直接给任意最多三位小数的非负价格，不提供 A/B/C 选项。每次更新合同都按当时分支自己的已结算记录调用同一模型；只有请求字节相同才能命中缓存。输出超界按事前给出的申请边界裁剪，记录原报价、裁剪比例、与参考价不同的比例、终局和尾部损失。两种模型各自同种子保留/涨/降 4% 至第60轮，不按是否盈利删去任何报价。网络仅访问本地模型端口，不增加商业账单。四种环境等量，选择器仍为冻结 delayed.inferred。
