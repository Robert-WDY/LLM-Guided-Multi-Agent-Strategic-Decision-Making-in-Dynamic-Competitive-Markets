# 真实经营模型的自主复核（探索性）

在数字报价采集期间追加，不将其称为新的人类样本或独立企业现场确认。对两个未参加开发的经营模型、两个市场、全 192 个数值报价种子复用同状态三条终局路径。若冻结建议器要改价，将实际原草稿、建议申请价、可见的历史及合同期限交回同一经营模型，允许自主保留或采用。响应必须严格为 A/B，余额和未来盈利不可见。对每个建议同时交换两个选项的字母次序，实际采纳决策由独立种子哈希预定哪种次序生效；另报顺序敏感率。无干预建议时默认维持原草稿。比较事前经营模型自选相对保留、以及相对强制采用。所有金额均来自各自真实模型续报的已存模拟结算。该指标仅识别该反馈合同内向 LLM 提供一个二选一建议的模拟效应，不能解释真人采纳、客户成交或真实净利润。
