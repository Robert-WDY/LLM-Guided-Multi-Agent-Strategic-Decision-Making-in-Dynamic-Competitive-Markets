# 四家独立报价的安装试验（首次终局前锁定）

60轮。冻结上一阶段公开报价模型 inferred 与直接估值 direct，三位对手用已结算报价的中位数投影到原双边接口。每次各方法都计算同一组保留和±4%候选及两个分数模型，安装只决定执行哪一个，双方使用完全相同的信息、模型调用和计算上限。原计划指保留该轮经营模型已提交的草稿，下一合同照常重新报价。第1–6轮照原协议共同预热。第7轮起每4轮由四位独立经营者重新报一次价，第19–55轮每个四轮合同允许复核（10次），最后一期续价至60轮。四家先同时提交，再统一结算。实际退出或边界裁成相同价计入分母。

原生生鲜与四厂商 EconEvals 结算各 3 组×48 个种子，分别从 180000、181000 起，每组内连续编号；第三个新场景为有外部选择、每期预约容量、未满足需求流失及已招致固定成本的四家预约服务，用原外部估值器零再训练迁移，从182000起，3组×24个种子。三组是全部均衡、全部现金缓冲型（完整人格从未用于训练或规则调试）、每家每局独立从均衡、现金缓冲、扩大客源、稳定服务等四种经营偏好中等概率抽取并固定。身份不提供给建议器；干预前不读取个性组结果。个人偏好只进入经营模型提示。按12种子成块轮换一企安装的四个座位、两企安装的全部六种组合，四企全装，0企共享基线；单家公司比较始终用同种子同一座位。报告固定安装全程的总效应、未安装者溢出、四家全装每家均值、同价率和离散度（只计在营者）、价格水平及尾部。不能将不同企业或轮次视为独立种子。

使用本地 SmolLM2 1.7B 固定权重；默认温度 .85，每家每个新合同独立随机流，各政策间同座位配对。草稿为模型自行选的相对反馈价的9个数值档（−8%、−6%、−4%、−2%、0、+2%、+4%、+6%、+8%）。每个只含已结算的市场、人格、相对价格、销量和利润趋势的完整提示，从真实模型获得实际9档概率，按各自独立随机数抽样；控制组另按同一分布众数经营。每组最后一个完整12种子区块改用服务端按座位、日期独立 seed 实际采样，全部政策分支续报至终局，以核验非缓存实时路径。温度不会强迫四家报不同价格，市场按自己的精度/约束执行。商业预算新增0。保留实际响应与足以回放每个分支的记录。

原门槛按每个预定机会：外部+5、生鲜+20,000模拟元，种子配对自举单侧98.75%下界超过门槛；实际放行覆盖≥10%，亏损率单侧98.75%精确上界≤10%。另设一企只在预抽的单个合同（第23–43轮）有一次机会，准确复用旧计量和风险分母。持续安装另报全局增量/每家10次预定机会；对1/2/4各自预抽一个已装座位和一个日期，仅跳过该次建议，随后双方按原安装继续到终局，比较四轮内和期后损益，估实际放行的尾险。每种子每覆盖只贡献一个风险探针。不把全局最差损失混作单次损失。跨场景数值单位不能合并；预约场景的+5仅作迁移参照。各人格、覆盖率、仅服务端子样本和事后最差案例作诊断；区间不覆盖所有探索性比较的家族错误。按种子分层报告，不因结果追样。最差案例做现金流分解、轮次、同一市场反事实核对。
