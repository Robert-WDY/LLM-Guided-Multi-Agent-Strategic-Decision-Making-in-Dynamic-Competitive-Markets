# 公开定价、固定有效期与事先弃权

独立种子块。开发 51200 起 8 个，校准 52300 起 24 个，确认 53500 起 48 个。真实 Agent 另从 54800 起。整局外部 60 轮、原生 60 轮；首六轮三种价格各持有两轮，其后四轮一次，局末截短。历史限己方已执行价格、销量、利润和已结算对手价格。对手、未来需求、分支标签均在评估器内。保持当前轮其余经营动作与相同来源的原计划一致。

相同种子配对稳定、需求永久上/下移、对手从近固定切换；确认时补入校准未见的反方向反应。每个种子的变化时刻在中期错开。A 预热利润最佳后锁价，B 按已实现跨周期利润试价，C 无条件公开回应，D 按我方滞后变价预测公开回应，W 无条件多搜价格，G 仅在 D 的分数超过校准阈值时接管 B。C、D 每候选五个价格、九条轨迹；W 为十五个价格、三条轨迹，每次完整决策 180 个预测转移。C/D/W 选择正分才更改。实际 CPU 可异。另测连续保留原生规则价格或外部初始价。

按种子聚类，利润用 0.99 折现，报告配对均差、两侧 95% bootstrap 区间、逐场景结果。响应为与未变化孪生轨迹连续两轮执行价偏离至少 1% 的首次时间，连同未响应率、相对冻结价的变化后收益报告。事先分数在 B 路径的完整周期机会产生；先封存分数再给替换和保留定价的两条分支结算，比较实际四轮利润。连续收益、覆盖率、拒绝中仍有利的比例、损失率和排序能力一起报告。阈值只看校准集。风险以发生干预的种子中任何干预条件整局亏于 B 的比例计算单侧 95% 精确上界。两市场分别要求 G 相对 B 和同预算简单搜索利润区间下界为正、实际覆盖至少 10%、风险上界不超过 10%。未达标保留 B 为研究比较对象，G 不自动启用。校准没有合格主动阈值时，保留弃权，并独立评估诊断用主动阈值。模型实验单独看实际草稿和接管后各自反馈的轨迹。API 总额保守预留不超过 50 元。
