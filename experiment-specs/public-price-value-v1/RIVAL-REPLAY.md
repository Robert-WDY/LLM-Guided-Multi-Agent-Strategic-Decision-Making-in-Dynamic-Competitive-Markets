# 对手回应机制复核

主设计完成规则盲测后新增的机制实验，不与主设计合并。只用外部双寡头的 80 个新规则种子 96000–96079，四个条件各 20。沿用冻结建议器和四轮合同。先结算保留原计划的完整报价轨迹，然后在同一来源分别涨价和降价。每个方向比较两种世界，一种对手按原协议实时回应，另一种对手逐轮重放保留时的价格。其余设定相同，包括需求冲击与本企业后续依自身反馈重新决策。对手重放只是评估干预，不能传给建议器。

验收必须逐轮完全复原保留路径，且在稳定和纯需求变化环境中两种世界的所有分支完全相同。按固定种子的成对收益差报告机制效应、绝对效应及两种选价策略差异。只要任一公开条件下对手实际产生响应，却无法验证条件选价胜过无条件模型，就区分“市场存在策略互动”和“建议器利用了它”。这是对机制的复核，不扩大真实模型样本或调整策略。
