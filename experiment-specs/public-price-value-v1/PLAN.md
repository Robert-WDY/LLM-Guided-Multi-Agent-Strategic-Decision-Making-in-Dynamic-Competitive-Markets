# 公开报价与原生建议器的终局验收

在读取本批终局标签前固定以下设计。目标是一次决策相对同一企业原计划的剩余折现利润，折现因子 .99；未干预的公共前缀抵消。价格合同持续四轮，之后各分支根据自己已结算历史重新制定原计划。基础 Agent 可以使用自身经营记录，严格公开的建议层只接收双方过去已经结算的报价、当前草稿与轮次。代替任何真实账目作为输入都会违反这个合同。

* EconEvals 和生鲜各用独立编号范围的 96 个规则训练种子（91000–91095）、40 个校准种子（92000–92039）、80 个盲测种子（93000–93079）。每个市场内四种环境依次轮换，两个市场之间不合并。包括稳定、需求冲击、对手改为跟随/压价、对手改为反向响应。单次机会在第 23–43 轮内按种子预定，至第 60 轮。三条分支分别保留、申请涨 4%、申请降 4%。约束、缺货及退出由市场正常结算。
* 规则轨迹用于拟合两种固定容量的终局价值回归（ExtraTrees，96 棵、叶子至少 8 个，固定随机数）。各自用同样的两个候选、过去 24 轮报价、现草稿、历史波动及相对价格。唯一差别是候选的滞后一轮对手预测使用项目现有价格变动分桶条件分布或无条件分布；两种都做同样数量的预测。校准以预测的更优方向的得分中位数为门槛，且要求得分为正。始终采纳、保留原计划和相同覆盖率随机放行是额外对照。对所有拒绝样本也结算。成交方向与申请不同、约束重合时按意向处理。预测器不读取环境类别、种子、真参数、销量、成本、利润或对手私有变量；训练标签允许来自已经结束的模拟。
* 每市场随后用 12 个新种子 94000–94011；DeepSeek / 豆包按每四个条件块轮换分配，使两个提供方均涉及四类环境。三条路径均由同一家模型继续决策到第 60 轮。前缀、去重命中、无效草稿回退以及共享预算单独核查。累计 50 元优先于样本数量；如预算不足仅报告实际完整例数。真实组独立报告，不与规则组合并。
* 另以原生可靠建议器 research 模式，24 个生鲜新种子 95000–95023，三类供需条件平衡，20 轮市场第 5 轮干预。比较 conditional / generic（相同候选上限 6、预算 500），项目标准 public 可见性含企业自身经营信息。对两个模式保留的最佳未采纳候选也强制执行一次，后续原 Agent 按各自状态重新决策直到终局。冻结公开历史，检查回放首轮及继续政策。该组草稿是规则 Agent；不与真实定价合并。
* 每个市场分别以种子为单位作配对自举 95% 区间。主要两项为条件策略经过门控相对保留、相对同预算无条件门控的终局差。两项在两个市场及真实复验下界均大于零才支持跨市场优势。弃权要比同覆盖率随机放行更赚钱，且放行机会的损失率单侧 95% 上界不超过 10%、覆盖至少 10%。全弃权不能通过。另报错放、错拒、理想事后选价的上限和条件分类的结果。小样本复验只作独立估计。达到预定样本与完整性检查后即按标准作结论，不因结果不显著而调阈值、补挑种子。
