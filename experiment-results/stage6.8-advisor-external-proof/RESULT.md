# Stage 6.8 Advisor 外部证明实验

状态：预注册实验完成；真实 LLM 门禁关闭。

## 实验对象

- 冻结版本：`strategic-research-mvp-v0.7.0`
- Advisor：`pareto_reliable_v6`
- Forecast Profile：`sha256:54d6a5c2dadbba2c74442caad8cef65293d7031876b2b58d33e7d51b1ed47de2`
- 外部历史真实 LLM Episode：6 个
- 独立 Seed：4 个
- 冻结回合窗口：45 个
- 新增真实模型调用、Token、费用：0

## 主要结果

逐项 Forecast 共 168 条，方向一致 152 条，准确率 90.48%。65 个正向且满足单项条件的候选中，冻结 Profile 放行 37 个，Coverage 56.92%；37 个放行候选的方向准确率为 100%，权威负收益数为 0。因此边际 Forecast 放行门禁通过。

最终动作与历史真实 LLM 动作使用相同状态、相同后续对手动作和相同随机轨迹结算：45 个窗口中 33 个提高、7 个相同、5 个降低；平均企业价值提高 705,625 分，平均反事实 Regret 降低 705,625 分。六个 Episode 中五个均值非负，但 `belief-real-paired-703` 平均降低 186,162 分；最差窗口降低 1,719,605 分。预注册要求最差 Episode 均值非负且最差窗口不低于 −1,000,000 分，因此结果门禁失败。

四个 Seed 聚类均值的双侧精确符号检验 `p=0.625`，不支持统计学一般结论。当前只能表述为“平均方向有利，但负尾部仍未解决”。

## 失败法医结论

5 个负窗口全部发生在 v6 Reliability Gate 失败后执行安全回退：3 次 `status_quo`，2 次 `risk_buffer`。五个历史 LLM 动作均不在 Advisor 候选集合内；五个最终回退动作在权威候选排名中均不是第一。

最严重的 Seed 703 第 3 轮中，v6 把价格从历史动作的 10,636 分降至 9,800 分，并移除广告和服务投入。Shapley 分解显示价格变化贡献约 −2,031,616 分，是总损失 −1,719,605 分的主要来源。另外两个保守人格负例主要来自过量韧性投入。说明已经通过的边际 Forecast Profile 没有覆盖“门禁失败后的整个 fallback 动作是否优于当前可行策略”这一问题。

## 结论边界

本实验否定“v6 已稳定改善所有未见状态”，但支持两个较窄结论：

1. 冻结 Forecast Profile 在本外部样本中有效过滤了逐项边际负收益候选；
2. v6 相对历史真实 LLM 动作的平均结果更好，但 fallback 的候选覆盖与尾部安全仍不足。

在修复 fallback 定义并使用新的未见 Episode 验证前，不执行最多 6 次真实 LLM 复测，不进入大规模实验。
