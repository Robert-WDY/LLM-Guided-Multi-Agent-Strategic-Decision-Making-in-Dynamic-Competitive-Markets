# Fresh Market Lab v4

Engineering MVP v4 的展示前端。页面不包含市场份额、需求、利润或事件公式，
所有结果都来自 Python `MarketEnv.step()` API。

本地运行时先启动仓库根目录的市场 API：

```powershell
$env:PYTHONPATH="src"
python -m game_theory_agent.api
```

再启动前端：

```powershell
cd frontend
npm ci
npm run dev
```

默认 API 地址为 `http://localhost:8010/api`，可通过
`NEXT_PUBLIC_MARKET_API_URL` 修改。

页面支持：

- 单公司经营视角：只控制一家企业，其他公司由透明规则代理决策；
- 单公司模式采用桌面一屏式经营控制台，公司状态、动作配置、公开市场和风险信息并排展示；
- 决策过程固定在单个视口内，解释内容按需展开，小屏设备自动切换为分栏堆叠；
- 公司驾驶舱：健康度、现金、份额、单均毛利、产能与五类诊断因子；
- 基于当前状态与风险信号的决策建议；
- 决策前展示上一轮公开市场快照、平均挂牌价、成交均价、市场销售额与流失口径；
- 对价格、广告、服务、产能、韧性和事故维修提供生效时间、影响机制与使用提示；
- 逐轮市场份额、公司销售额及需求—成交—流失统计表；
- 终局市场回溯：逐轮行动、状态变化、机制解释、关键转折与成败归因；
- 随时切换回四家公司联合操作的市场全景；
- 2～4 家公司；
- 连续价格、广告、服务、产能和韧性预算；
- 风险信号、活动市场事件和公司事故维修；
- 现金、产能、品牌、声誉和韧性状态；
- Outside Option、缺货流失和后端 State Hash；
- 可选 5 / 10 / 15 / 20 轮的利润及状态转移轨迹；
- 随机或固定 Seed，以及均衡、价格敏感、品质偏好、服务偏好或随机市场。

回溯中的“原因”来自市场模型的状态转移规则和指标变化，是可核查的机制解释；
它不声称证明现实世界中的严格因果关系。
